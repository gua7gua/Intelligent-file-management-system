# 接口文档

> 本文档根据 `业务场景.md`、`数据库设计.md`、`技术架构.md` 和原型页面整理。接口统一以 `/api` 为前缀，面向 Spring Boot + Sa-Token + MyBatis-Plus 实现。

## 1. 通用约定

### 1.1 认证

- 登录成功后由后端签发 token。
- 前端后续请求携带 `Authorization: Bearer <token>`。
- 未登录可访问公众首页、公开检索、公开详情、登录、公众注册、忘记密码和字典类只读接口。
- 管理、移交、内部查阅、下载、借阅、审批等接口必须登录。

### 1.2 响应结构

普通 JSON 接口统一返回：

```json
{
  "code": "OK",
  "message": "success",
  "data": {},
  "traceId": "请求追踪 ID"
}
```

分页返回：

```json
{
  "records": [],
  "pageNo": 1,
  "pageSize": 20,
  "total": 100,
  "hasNext": true
}
```

文件下载、PDF/Excel 导出可直接返回文件流；失败时仍返回统一错误结构。

### 1.3 常用分页参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `pageNo` | integer | 否 | 默认 1，从 1 开始 |
| `pageSize` | integer | 否 | 默认 20，最大 100 |
| `sortBy` | string | 否 | 只能使用后端白名单 |
| `sortOrder` | string | 否 | `asc` / `desc` |

### 1.4 错误码

| HTTP | code | 说明 |
|------|------|------|
| 400 | `BAD_REQUEST` | 参数格式错误、缺少必填字段、枚举值非法 |
| 401 | `UNAUTHORIZED` | 未登录或 token 无效 |
| 403 | `FORBIDDEN` | 角色、密级或数据范围不足 |
| 404 | `NOT_FOUND` | 业务对象不存在或当前用户不可见 |
| 409 | `BUSINESS_CONFLICT` | 当前状态不允许操作、重复借阅、重复审批、架位已占用 |
| 413 | `PAYLOAD_TOO_LARGE` | 上传文件超过配置上限 |
| 415 | `UNSUPPORTED_MEDIA_TYPE` | 文件格式或 MIME 类型不允许 |
| 422 | `VALIDATION_FAILED` | 业务规则校验不通过或 AI 结果含不可用字段 |
| 429 | `TOO_MANY_REQUESTS` | 登录、短信验证码、AI 调用等限流 |
| 500 | `INTERNAL_ERROR` | 未预期系统错误 |
| 502 | `EXTERNAL_SERVICE_ERROR` | AI、MinIO、ClamAV、短信等外部服务异常 |

### 1.5 关键枚举

| 枚举 | 值 |
|------|----|
| `sourceType` | `transfer`、`collection`、`compilation` |
| `carrierStatus` | `electronic`、`paper_electronic`、`paper` |
| `retentionPeriod` | `10y`、`30y`、`permanent` |
| `securityLevel` | `0`、`1`、`2`、`3`、`4` |
| `openStatus` | `open`、`closed` |
| `batchStatus` | `draft`、`pending_transfer`、`pending_contact`、`pending_receive`、`received`、`partially_received`、`rejected`、`archived`、`shelved` |
| `itemStatus` | `draft`、`pending_acceptance`、`accepted`、`rejected`、`pending_archive`、`archived` |
| `archiveLifecycleStatus` | `pending_shelf`、`normal`、`pending_destruction`、`destroyed` |
| `borrowStatus` | `applied`、`rejected`、`approved`、`voucher_issued`、`checked_out`、`returned`、`abnormal_return` |
| `approvalStatus` | `pending`、`approved`、`rejected` |

清单状态中文展示必须结合 `sourceType` 映射，例如 `rejected` 在移交侧显示“已回退”，在征集侧显示“已拒绝”。

## 2. 公共与字典

### 2.1 获取全部字典

`GET /api/dictionaries`

角色：未登录、所有登录用户

说明：返回角色、门类、载体状态、保管期限、密级、开放状态、业务状态、上传白名单等前端基础字典。

查询参数：无。

返回 `data`：

```json
{
  "roles": [],
  "categories": [],
  "carrierStatuses": [],
  "retentionPeriods": [],
  "securityLevels": [],
  "openStatuses": [],
  "batchStatuses": [],
  "itemStatuses": [],
  "systemConfigs": {
    "uploadAllowedExtensions": ["pdf", "docx"],
    "uploadMaxFileSizeMb": 200
  }
}
```

校验：无登录要求，但不返回敏感配置值、AI Key、数据库连接等运行密钥。

### 2.2 获取单个字典

`GET /api/dictionaries/{dictCode}`

角色：未登录、所有登录用户

路径参数：

| 参数 | 类型 | 说明 |
|------|------|------|
| `dictCode` | string | 如 `categories`、`roles`、`securityLevels`、`batchStatuses` |

返回：对应字典数组。

### 2.3 业务附件下载说明

本系统**不提供统一的附件下载端点**；各业务附件通过所属业务对象的专用端点下载，均按业务对象鉴权，下载行为写入 `audit_logs`，档案正文类下载写入 `archive_access_logs`：

| 附件类型 | 下载端点 | 对应章节 |
|----------|----------|----------|
| 移交清单 PDF | GET `/api/transfer/batches/{batchId}/export` | §4.11 |
| 接收回执 | GET `/api/admin/reception/batches/{batchId}/receipt` | §7.7 |
| 借阅凭证 | GET `/api/internal/borrow-requests/{requestId}/voucher` | §11.10 |
| 编研正文 | POST `/api/admin/compilations/{compilationId}/generate` | §19.5 |
| 销毁现场照片 | 随销毁清册详情（§15.2）查看 | §15 |

## 3. 认证与公众账号

### 3.1 登录

`POST /api/auth/login`

角色：未登录用户

请求：

```json
{
  "loginName": "admin",
  "password": "123456",
  "portal": "admin"
}
```

字段说明：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `loginName` | string | 是 | 登录名、工号或手机号 |
| `password` | string | 是 | 密码 |
| `portal` | string | 是 | `public`、`internal`、`transfer`、`admin`、`approval` |

返回：

```json
{
  "token": "token",
  "user": {
    "id": 1,
    "realName": "小陈",
    "userType": "internal",
    "roles": ["front_archivist"],
    "organizationId": 1,
    "maxSecurityLevel": 2,
    "dataScope": "all"
  },
  "defaultRoute": "/admin/overview"
}
```

校验：

- 用户必须为 `active`。
- 所选门户必须与用户角色匹配。
- 登录失败限流，成功和失败均记录审计日志。

### 3.2 登出

`POST /api/auth/logout`

角色：已登录用户

请求：无。

返回：`true`。

校验：清理当前 token 会话并记录审计日志。

### 3.3 当前用户

`GET /api/auth/me`

角色：已登录用户

返回当前用户、角色、组织、权限范围和可访问菜单。

### 3.4 公众注册

`POST /api/public/auth/register`

角色：未登录用户

请求：

```json
{
  "phone": "13800000005",
  "smsCode": "123456",
  "password": "123456",
  "realName": "小周"
}
```

返回：注册后的公众用户基础信息。

校验：

- 手机号唯一。
- 验证码有效。
- 默认创建 `userType = public`，分配 `public_user` 角色。

### 3.5 发送验证码

`POST /api/public/auth/sms-code`

角色：未登录用户

请求：

```json
{
  "phone": "13800000005",
  "scene": "register"
}
```

字段：`scene` 可为 `register`、`forgot_password`。

校验：手机号格式正确，同手机号和同 IP 限流。

### 3.6 公众找回密码

`POST /api/public/auth/reset-password`

角色：未登录用户

请求：

```json
{
  "phone": "13800000005",
  "smsCode": "123456",
  "newPassword": "newPassword"
}
```

返回：`true`。

校验：仅允许公众账号通过此接口找回密码，内部账号由系统管理员重置。

## 4. 移交单位门户

### 4.1 移交工作台统计

`GET /api/transfer/dashboard`

角色：`transfer_user`

说明：移交工作台展示草稿、待移交、部分接收、已接收、已入库、已上架、已回退数量和最近清单。

返回：

```json
{
  "summary": {
    "draft": 1,
    "pendingTransfer": 2,
    "partiallyReceived": 1,
    "received": 1,
    "archived": 3,
    "shelved": 2,
    "rejected": 0
  },
  "recentBatches": []
}
```

校验：只统计当前用户所属单位和本人可见的 `sourceType = transfer` 清单。

### 4.2 查询移交清单列表

`GET /api/transfer/batches`

角色：`transfer_user`

查询参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `status` | string | 否 | 批次状态 |
| `keyword` | string | 否 | 清单号、标题 |
| `archiveYear` | integer | 否 | 档案所属年度 |
| `pageNo` / `pageSize` | integer | 否 | 分页 |

返回：分页清单，包含 `batchNo`、`title`、`status`、`statusText`、`itemCount`、`submittedAt`、`expectedTransferDate`。

校验：只返回当前移交单位清单。

### 4.3 创建移交清单草稿

`POST /api/transfer/batches`

角色：`transfer_user`

请求：

```json
{
  "title": "2025 年度财政会计档案移交清单",
  "departmentName": "财务处",
  "contactPhone": "13800000003",
  "archiveYear": 2025,
  "expectedTransferDate": "2026-05-20",
  "items": [
    {
      "inputTitle": "2025 年第一季度会计凭证",
      "pageCount": 128,
      "retentionPeriod": "30y",
      "carrierStatus": "paper_electronic",
      "securityLevel": 1,
      "openStatus": "closed",
      "allowDigitization": true,
      "electronicFormat": "PDF",
      "expectedFilename": "2025Q1-accounting-vouchers.pdf",
      "formedDate": "2025-03-31"
    }
  ]
}
```

返回：清单详情。

校验：

- `sourceType` 固定为 `transfer`。
- 批次初始状态为 `draft`，条目为 `draft`。
- 不接收文件本体，`expectedFilename` 仅来自浏览器本地解析或人工输入。
- 至少一条清单条目。

### 4.4 获取移交清单详情

`GET /api/transfer/batches/{batchId}`

角色：`transfer_user`

返回：批次字段、条目列表、接收结果、回退原因、回执附件。

校验：当前用户所属单位必须匹配清单 `organizationId`。

### 4.5 更新移交清单草稿

`PUT /api/transfer/batches/{batchId}`

角色：`transfer_user`

请求：同创建接口。

返回：更新后的清单详情。

校验：

- 仅 `status = draft` 可编辑。
- 提交后清单只读。

### 4.6 删除移交清单草稿

`DELETE /api/transfer/batches/{batchId}`

角色：`transfer_user`

返回：`true`。

校验：仅 `draft` 可删除。

### 4.7 新增移交清单条目

`POST /api/transfer/batches/{batchId}/items`

角色：`transfer_user`

请求：单条 `item` 字段，同创建清单中的条目。

返回：新增条目。

校验：批次必须为 `draft`。

### 4.8 更新移交清单条目

`PUT /api/transfer/batches/{batchId}/items/{itemId}`

角色：`transfer_user`

请求：单条条目字段。

返回：更新后的条目。

校验：批次必须为 `draft`，条目属于该批次。

### 4.9 删除移交清单条目

`DELETE /api/transfer/batches/{batchId}/items/{itemId}`

角色：`transfer_user`

返回：`true`。

校验：批次必须为 `draft`，删除后至少保留一条条目。

### 4.10 提交移交清单

`POST /api/transfer/batches/{batchId}/submit`

角色：`transfer_user`

请求：无。

返回：提交后的清单详情。

状态变化：

- 批次 `draft -> pending_transfer`
- 条目 `draft -> pending_acceptance`
- 写入 `submittedAt`
- 生成或确认 `batchNo`

校验：

- 必填字段完整。
- 载体状态、保管期限、密级、公开状态合法。
- 电子载体条目建议填写 `expectedFilename` 和 `electronicFormat`。
- 提交后写入审计日志。

### 4.11 导出移交清单 PDF

`GET /api/transfer/batches/{batchId}/export`

角色：`transfer_user`

返回：PDF 文件流。

校验：

- 批次必须已提交或已进入后续状态。
- 只导出当前单位可见清单。
- 可将 PDF 记录到 `business_attachments`，类型 `transfer_pdf`。

## 5. 公众门户与征集

### 5.1 公众概览

`GET /api/public/dashboard`

角色：`public_user`

返回：

```json
{
  "collectionSummary": { "total": 10, "draft": 2, "inProgress": 5, "completed": 3 },
  "recentCollections": [],
  "downloadLogs": [
    { "id": 1, "archiveId": 7, "archiveNo": "KLMY-2024-001", "title": "某档案题名",
      "archiveFileId": 9, "accessType": "download", "ipAddress": "1.2.3.4",
      "accessedAt": "2026-06-16T10:00:00+08:00" }
  ],
  "stats": {
    "openArchiveCount": 128, "electronicFileCount": 56,
    "collectionCount": 30, "latestOpenCount": 12,
    "myPendingCollections": 5, "myDownloadCount": 15
  },
  "user": { "realName": "小周", "phone": "138****0005", "status": "active" },
  "summarizedAt": "2026-06-16T10:00:00+08:00"
}
```

字段说明：

- `downloadLogs[*]`：本人下载记录，每条含 `archiveNo`（档号）、`title`（档案题名），便于直接展示。
- `stats`：公开馆藏统计 + 本人统计。
  - `openArchiveCount`/`electronicFileCount`/`collectionCount`/`latestOpenCount` 口径见 §5.12，与公开检索一致。
  - `myPendingCollections` = 本人处于处理中的征集数（= `collectionSummary.inProgress`）。
  - `myDownloadCount` = 本人下载日志总数。
- `user`：当前公众用户基础资料，`status` 取值 `active`/`disabled`。

校验：

- 只返回当前公众用户本人征集清单和下载记录。
- 公开统计口径：`security_level=0 AND open_status=open AND lifecycle_status=normal`（与 §5.2 一致）。

### 5.1.1 公开馆藏统计

`GET /api/public/stats`

角色：未登录用户、`public_user`（公众首页门面数据，免登录）

返回：

```json
{
  "openArchiveCount": 128,
  "electronicFileCount": 56,
  "collectionCount": 30,
  "latestOpenCount": 12,
  "categories": [ { "name": "文书", "count": 80 } ]
}
```

字段说明：

- `openArchiveCount`：公开档案数（`security_level=0 AND open_status=open AND lifecycle_status=normal`）。
- `electronicFileCount`：关联到公开档案的电子文件数（`archive_files JOIN archives`，同三条件 + `archive_files.deleted_at IS NULL`）。
- `collectionCount`：全部征集批次总数（`intake_batches.deleted_at IS NULL`）。
- `latestOpenCount`：近 30 天开放的公开档案数。
- `categories`：公开档案按门类分组计数。

校验：与 §5.2 相同，`public_search.enabled` 为 false 时返回 `BUSINESS_CONFLICT`。

### 5.2 公开档案检索

`GET /api/public/archives/search`

角色：未登录用户、`public_user`

查询参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `keyword` | string | 否 | 题名、档号、责任者、标签模糊检索 |
| `archiveNo` | string | 否 | 档号 |
| `title` | string | 否 | 题名 |
| `categoryId` | integer | 否 | 门类 |
| `formedYearStart` | integer | 否 | 起始年度 |
| `formedYearEnd` | integer | 否 | 结束年度 |
| `responsibleText` | string | 否 | 责任者 |
| `tagIds` | string | 否 | 逗号分隔标签 ID |
| `sourceType` | string | 否 | 来源 |
| `carrierStatus` | string | 否 | 载体状态 |
| `hasElectronicFile` | boolean | 否 | 是否有电子文件 |
| `pageNo` / `pageSize` | integer | 否 | 分页 |

返回：分页公开档案摘要。

校验：

- 后端强制追加 `securityLevel = 0 AND openStatus = open AND lifecycleStatus = normal`。
- 不返回密级明细、库房架位、盒号、内部备注。
- 公开检索开关 `public_search.enabled` 为 false 时返回 `BUSINESS_CONFLICT`。

### 5.3 公开档案详情

`GET /api/public/archives/{archiveId}`

角色：未登录用户、`public_user`

返回：公开元数据、可预览/可下载文件摘要。

校验：同公开检索过滤；记录 `view_metadata` 访问日志。

### 5.4 公开档案预览

`GET /api/public/archive-files/{fileId}/preview`

角色：未登录用户、`public_user`

返回：预签名 URL 或文件流。

校验：

- 文件所属档案必须非密、公开、正常。
- `fileStatus = normal`。
- 写入 `archive_access_logs`，`accessType = preview`。

### 5.5 公开档案下载

`GET /api/public/archive-files/{fileId}/download`

角色：`public_user`

返回：预签名 URL 或文件流。

校验：

- 必须登录。
- 文件所属档案必须非密、公开、正常。
- 写入 `archive_access_logs`，`accessType = download`。

### 5.6 公众 AI 检索 JSON 生成

`POST /api/public/archives/ai-query`

角色：未登录用户、`public_user`

请求：

```json
{
  "text": "查找 2000 年以后公开的老城改造影像资料"
}
```

返回：

```json
{
  "ruleType": "publicSearchQuery",
  "conditions": {
    "keyword": "老城改造",
    "categoryCode": "audio_video",
    "formedYearStart": 2000
  },
  "rawJson": {}
}
```

校验：

- AI 只生成查询条件，不直接执行检索。
- 只注入公开范围标签和固定门类，不注入档案正文。
- JSON 校验失败最多重试 `ai.search_max_retries` 次。

### 5.7 查询本人征集清单

`GET /api/public/collections`

角色：`public_user`

查询参数：`status`、`keyword`、`pageNo`、`pageSize`。

返回：分页征集清单。

校验：只返回当前公众用户本人创建的 `sourceType = collection` 清单。

### 5.8 创建征集清单草稿

`POST /api/public/collections`

角色：`public_user`

请求：

```json
{
  "title": "小周家庭照片捐赠意向",
  "contactName": "小周",
  "contactPhone": "13800000005",
  "archiveYear": 1998,
  "items": [
    {
      "inputTitle": "1998 年家庭照片一组",
      "carrierStatus": "electronic",
      "electronicFormat": "JPG",
      "expectedFilename": "family-photos-1998.zip",
      "formedDate": "1998-07-01"
    }
  ]

```

返回：征集清单详情。

校验：

- `sourceType = collection`。
- 默认 `retentionPeriod = permanent`、`securityLevel = 0`、`openStatus = open`。
- 公众侧不上传文件本体。

### 5.9 获取征集清单详情

`GET /api/public/collections/{batchId}`

角色：`public_user`

返回：批次详情、条目、联系结果、接收状态、回执附件。

校验：仅本人可见。

### 5.10 更新征集草稿

`PUT /api/public/collections/{batchId}`

角色：`public_user`

请求：同创建征集清单。

返回：更新后的详情。

校验：仅 `draft` 可编辑。

### 5.11 提交征集清单

`POST /api/public/collections/{batchId}/submit`

角色：`public_user`

请求：

```json
{
  "agreementAccepted": true
}
```

返回：提交后的详情。

状态变化：

- 批次 `draft -> pending_contact`
- 条目 `draft -> pending_acceptance`
- 写入 `submittedAt` 和 `agreementAcceptedAt`

校验：

- 必须勾选在线捐赠协议。
- 当前用户待处理数量不超过配置上限。

凭证盖章口径：系统比较档案所属单位与借阅人单位——**本单位借阅**时「单位意见（盖章）」段文案不变；**跨单位纸质借阅**（档案所属单位 ≠ 借阅人单位）时改为「档案馆代原属单位（{原属单位名}）意见（档案馆盖章）」，由档案馆代原单位盖章。「档案馆归还确认（盖章）」段两种情形均不变。

### 20.5 创建研判任务

`POST /api/admin/analysis-tasks`

角色：`back_archivist`

```json
{

  }

```

- AI 只写 `analysis_items.suggestion`，不直接改档案。

## 23. 日志审计

### 23.1 查询审计日志

`GET /api/admin/audit-logs`

角色：`sys_admin`

查询参数：

| 参数 | 类型 | 说明 |
|------|------|------|
| `actorUserId` | integer | 操作人 |
| `actorType` | string | `internal`、`public`、`system` |
| `moduleName` | string | 模块 |
| `operationType` | string | 操作类型 |
| `businessType` | string | 业务类型 |
| `businessId` | integer | 业务 ID |
| `startedAt` / `endedAt` | datetime | 时间范围 |
| `cursor` / `limit` | string/integer | 游标分页 |

返回：

```json
{
  "records": [],
  "nextCursor": "cursor",
  "hasNext": true
}
```

每条记录字段（含联表富字段）：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | integer | 日志主键 |
| `actorUserId` | integer | 操作人 ID；`system` 类型为 null |
| `actorType` | string | `internal`、`public`、`system` |
| `actorName` | string | 富字段：操作人姓名，`system` 类型固定为「系统」，其余由 `users.real_name` 联表填充，缺失时为 `用户#<id>` |
| `moduleName` | string | 模块代号（如 `M03`、`M14`） |
| `moduleLabel` | string | 富字段：模块代号对应的中文标签（`M03 -> 电子文件上传`、`M14 -> 系统配置` 等），未命中时为 null |
| `operationType` | string | 操作类型 |
| `businessType` | string | 业务对象类型（如 `archive`、`borrow_request`） |
| `businessId` | integer | 业务对象 ID |
| `archiveNo` | string | 富字段：当 `businessType=archive` 时，联 `archives.archive_no` 填充档号（便于列表直接展示，无需再联表） |
| `detail` | object | JSONB 详情 |
| `ipAddress` | string | IP 地址 |
| `operatedAt` | datetime | 操作时间 |

校验：系统管理员可查操作日志，但默认不授予档案正文查看权限。

### 23.2 查询档案访问日志

`GET /api/admin/archive-access-logs`

角色：`back_archivist`、`sys_admin`

查询参数：`userId`、`archiveId`、`accessType`、`startedAt`、`endedAt`、`cursor`、`limit`。

返回：游标分页访问日志，每条记录字段（含联表富字段）：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | integer | 日志主键 |
| `userId` | integer | 访问人 ID；未登录公众为 null |
| `userType` | string | `internal`、`public`、`anonymous` |
| `actorName` | string | 富字段：访问人姓名，`users.real_name` 联表填充；未登录且 `userType=anonymous` 时为「匿名公众」 |
| `archiveId` | integer | 档案 ID |
| `archiveNo` | string | 富字段：档号，联 `archives.archive_no` |
| `title` | string | 富字段：档案题名，联 `archives.title` |
| `archiveFileId` | integer | 档案文件 ID；元数据查看时为 null |
| `accessType` | string | `view_metadata`、`preview`、`download` |
| `ipAddress` | string | IP 地址 |
| `accessedAt` | datetime | 访问时间 |

校验：系统管理员查看日志不等于可下载档案正文。
