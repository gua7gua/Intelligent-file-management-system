## 后台管理类深度操作（liu.back）— back-admin.spec.ts
> 补齐 back-core 未覆盖的管理类页面 CRUD（全宗 / 库房 / 保存 / 盘点）。每个用例自包含、幂等，停用/创建只作用于本次新建实体，不污染基线（F001-3 / 401-402）。

| 编号 | 场景 | 期望 |
|---|---|---|
| A-FONDS | 全宗 新建→编辑→停用 全生命周期 | 新建唯一全宗号成功；编辑改名保存（全宗号创建后不可改）；停用后状态置灰、按钮变「已停用」 |
| A-WAREHOUSE | 创建库房房间并自动生成架位 | 填库房号/名称/机架×层×盒位→「生成架位」→成功提示含架位数、启用库房指标 +1、新库房进房间列表 |
| A-PRESERVE | 立即数据库备份 | 默认「数据库备份」→「立即备份」→成功提示、备份任务列表 +1 |
| A-CHECK | 四性检测：解析档案→执行→出结果 | 解析 ARC-000040 出电子件→执行四性检测→检测结果分组出现 |
| A-INVENTORY | 建盘点任务→开始→填正常→提交 | 库房 401 × 会计（命中 12 件）→生成清单→开始盘点→逐行「正常」→提交确认→已完成 |

> 纸质档案上架见 [W-B-4](../tests/workflows/w-b-transfer.spec.ts)（纸质+电子载体闭环内：入库选档案盒→确认上架→预览）。
