# 10 · 登录与鉴权

> 对应代码：[tests/00-login/login.spec.ts](../tests/00-login/login.spec.ts) · 登录页对象 [support/pages/LoginPage.ts](../support/pages/LoginPage.ts)

## 用例

| 编号 | 场景 | 前置 | 期望 | 结果 |
|---|---|---|---|---|
| L-1~L-8 | 8 个角色逐一 UI 登录（账号+密码+选角色+提交） | 服务运行 | 落到对应门户默认页（/admin、/transfer、/internal、/public），登录表单卸载 | ✅ |
| L-9 | 错密码登录失败 | liu.back + 错密码 | 显示「登录失败」提示，停留在 /login（R3 修复：非「登录已过期」） | ✅ |
| L-10 | 选角色实时显示「登录后将进入：XX」 | 进入登录页 | 选移交/内部角色后 notice 文本随之变化 | ✅ |

## 覆盖的第三轮回归点
- 1.5 登录弹窗区分凭证错误与 token 过期（L-9 验凭证错误不跳转、不弹「登录已过期」）。
- el-select 点击坑：必须点 `.el-select` 容器而非内部 input（封装在 [support/el-select.ts](../support/el-select.ts)）。

## 登录加速
登录流程本身走 UI（L-*）；其余所有 spec 通过 `globalSetup` 用 API 预置各角色 `storageState`（含 localStorage token）复用，避免每个测试重复 UI 登录。
