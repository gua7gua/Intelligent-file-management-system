# 系统配置 - 原型设计

## 1. 页面概述

- 页面名称：系统配置
- 所属门户：管理后台
- 页面路径：`prototype/admin/system-settings.html`
- 使用角色：系统管理员
- 设计依据：`new-doc/业务场景.md` 场景十四，`new-doc/数据库设计.md` 中 `system_configs`、`audit_logs`。

## 2. 业务场景归属分析

本页面属于“系统管理员管理用户”场景中的系统配置部分，负责维护文件格式白名单、上传大小限制、AI 功能开关、公开检索开关、库房占用阈值、默认借阅天数和征集捐赠协议文案等系统参数。

上游输入为系统初始化配置和管理员维护值；页面内维护 `system_configs`；下游消费为文件上传校验、AI 功能启停、公开检索入口、库房告警、借阅默认到期日和征集协议展示。配置变更写入 `audit_logs`，但不替代档案业务审批。

涉及状态节点：

- 配置项：`editable = true / false`
- AI 开关：`ai.enabled = true / false`
- 公开检索开关：`public_search.enabled = true / false`

## 3. 用户与操作分析

角色：系统管理员。

主路径操作：

- 维护上传格式白名单和最大上传大小
- 开启或关闭 AI 功能
- 开启或关闭公开检索入口
- 设置库房占用告警阈值和默认借阅天数
- 维护征集捐赠协议文案
- 保存配置并记录审计日志

异常路径操作：

- 配置项不可编辑：禁用输入并提示原因
- 上传大小超出允许范围：阻止保存并提示限制
- 公开检索关闭：只关闭公众检索入口，不改变正式档案公开状态
- AI 关闭：页面提示业务流程回退为人工填写和手工筛选

## 4. 页面布局说明

页面使用管理后台统一壳层。内容区分为配置概览、文件上传配置、AI 与公开检索开关、业务默认参数、征集协议文案、变更审计和边界提示。

关键区域：

- 上传配置：`upload.allowed_extensions`、`upload.max_file_size_mb`
- 能力开关：`ai.enabled`、`public_search.enabled`
- 业务参数：`warehouse.usage_warning_threshold`、`borrow.default_days`、`collection.agreement_text`
- 审计提示：保存配置后写入 `audit_logs`

## 5. 交互逻辑说明

用户编辑配置后点击“保存配置”，页面模拟校验上传大小和白名单，成功后显示保存反馈。切换 AI 开关时提示 AI 不是主流程依赖；切换公开检索开关时提示不改变档案公开字段。添加格式按钮可向白名单加入新扩展名；征集捐赠协议文案保存后供公众提交前展示。

页面明确：系统配置只控制系统运行参数，密级调整、开放调整、销毁审批仍由业务审批流程处理，不可通过配置页直接替代。

## 6. 启发式自查记录

1. 系统状态可见性：配置值、开关状态和最近保存结果可见。
2. 系统与现实世界匹配：使用上传白名单、公开检索、默认借阅天数等业务语言。
3. 用户控制与自由：保存前可调整，开关变化有提示。
4. 一致性与标准：复用后台壳层、表单、按钮和状态标签。
5. 错误预防：上传大小和白名单保存前校验。
6. 识别而非记忆：配置键、含义和当前值同屏展示。
7. 灵活性与效率：支持快速添加白名单格式和启停开关。
8. 美观与简约设计：配置按上传、能力、业务参数和协议文案分组。
9. 帮助用户识别和修复错误：校验失败给出具体原因。
10. 帮助与文档：业务审批边界和 AI 依赖边界在页面提示中说明。
