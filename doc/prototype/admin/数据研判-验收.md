# 数据研判 - 验收

## 1. 验收范围

- 页面：数据研判
- 路径：`prototype/admin/data-analysis.html`
- 版本：静态高保真原型
- 验收依据：`数据研判-原型设计.md`、场景十二、`AI交互架构.md`、数据库表 `analysis_tasks`、`analysis_items`、`archives`、`archive_change_logs`

## 2. 功能验收项

| 验收项 | 验收标准 | 状态 |
|---|---|---|
| 后台统一壳层 | 页面包含左侧导航、顶部栏和管理后台内容区 | 通过 |
| 公共样式引用 | HTML 引用 `../common/css/base.css`、`components.css`、`shell.css` | 通过 |
| 扫描控制 | 支持选择扫描范围、任务类型和每批数量 | 通过 |
| 任务状态 | 展示任务号、扫描数量、候选建议、已采纳数量和进度 | 通过 |
| AI JSON 展示 | 展示 `ruleType = dataAnalysis` 的结构化候选结果 | 通过 |
| 异常建议 | 展示缺失字段、分类冲突、标签建议等候选项 | 通过 |
| 只生成建议 | 页面明确采纳或不采纳建议不直接修改 `archives` | 通过 |
| 字段保护 | 页面列出受保护字段并禁止直接覆盖 | 通过 |

## 3. 交互验收项

| 验收项 | 验收标准 | 状态 |
|---|---|---|
| 开始扫描 | 点击后任务进入执行中并模拟完成，生成候选建议 | 通过 |
| 条目详情 | 列表只显示状态标签和详情入口，采纳/不采纳按钮位于详情区 | 通过 |
| 采纳建议 | 点击后建议状态变为已采纳，加入待处理队列 | 通过 |
| 不采纳建议 | 点击后建议状态变为已不采纳，正式档案不变化 | 通过 |
| 生成待补充清单 | 无采纳项时提示先采纳，有采纳项时生成后续处理反馈 | 通过 |
| AI 不可替代业务处理 | 页面提示后续需在档案管理页面人工处理并记录变更日志 | 通过 |

## 4. 启发式评估验收

1. 系统状态可见性：任务状态、进度、建议数量和处理状态清楚，符合。
2. 系统与现实世界匹配：使用缺失字段、分类冲突、标签建议等术语，符合。
3. 用户控制与自由：建议可采纳或不采纳，符合。
4. 一致性与标准：复用后台壳层、AI 结果框、表格和状态标签，符合。
5. 错误预防：AI 建议不直接改正式档案，符合。
6. 识别而非记忆：字段边界和 JSON 同屏展示，符合。
7. 灵活性与效率：支持范围、类型和批量数量选择，符合。
8. 美观与简约设计：扫描、建议、队列和边界分区清楚，符合。
9. 帮助用户识别和修复错误：建议包含问题描述和处理方向，符合。
10. 帮助与文档：AI 安全边界已在页面提示中说明，符合。

## 5. 问题记录

无阻断问题。静态原型中的扫描和 AI JSON 为模拟数据，后续实现需接入 AI 白名单过滤和正式业务接口。

## 6. 验收结论

通过。页面满足“数据研判只生成异常建议，不直接修改正式档案”的业务边界。
