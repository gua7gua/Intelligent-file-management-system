配置项明细

配置键 当前值 类型 可编辑 说明
upload.allowed_extensions pdf, docx, jpg, png, mp4 json 是 文件上传格式白名单
ai.enabled true boolean 是 AI 功能统一开关
public_search.enabled true boolean 是 公众公开检索入口
collection.agreement_text 捐赠协议文案 string 是 公众提交征集清单前展示并勾选同意
security.audit_retention permanent string 否 审计日志保留策略，不允许页面修改

配置边界

  • 上传
    只维护格式白名单和大小限制。
  • AI
    统一启停补全、检索 JSON 和数据研判建议。
  • 公开检索
    只控制公众入口，不直接改档案公开状态。
  • 征集协议
    公众提交时在线展示并记录同意时间。
    • 审批边界
    配置页不办理密级调整、开放调整或销毁审批；这些业务必须进入审批工作台并保留审批记录。
    审计要求
    保存配置写入 audit_logs，不可在页面删除审计记录。
