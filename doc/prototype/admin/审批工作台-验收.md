# 审批工作台 - 验收

## 1. 验收范围

- 页面：审批工作台
- 路径：`prototype/admin/approval.html`
- 版本：新版原型重建第 5 批

## 2. 功能验收项

| 编号 | 验收项 | 验收标准 | 状态 |
|------|--------|----------|------|
| F-01 | 审批类型 | 覆盖密级调整、开放调整、销毁清册审批 | 通过 |
| F-02 | 证据展示 | 密级/开放审批并列展示目标档案和凭证档案 | 通过 |
| F-03 | 清册快照 | 销毁审批展示清册快照、鉴定来源和审批结果 | 通过 |
| F-04 | 审批结果 | 通过后字段生效或清册待销毁；退回时目标对象不变 | 通过 |
| F-05 | 馆领导边界 | 明确馆领导审批即本馆批准凭证，不引入第三方节点 | 通过 |

## 3. 交互验收项

| 编号 | 验收项 | 验收标准 | 状态 |

## 4. 启发式评估验收

| 原则 | 评估结论 | 状态 |
