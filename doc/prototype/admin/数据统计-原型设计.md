# 数据统计 - 原型设计

## 1. 页面概述

- 页面名称：数据统计
- 所属门户：管理后台
- 页面路径：`prototype/admin/statistics.html`
- 使用角色：档案管理员（后台）、馆领导
- 设计依据：`new-doc/业务场景.md` 场景十二、场景十六，`new-doc/数据库设计.md` 中 `archives`、`intake_batches`、`borrow_requests`、`destruction_lists`、`backup_tasks`、`file_check_records`，以及 `module-portal-overview.puml`、`data-flow.puml`。

## 2. 业务场景归属分析

本页面属于“统计与研判”中的数据统计部分，是管理后台的只读统计入口。统计结果来自正式业务表的实时查询或简单定时汇总，不维护独立 BI 统计库，不通过前端录入统计数。

上游输入为正式档案、移交/征集批次、借阅申请、销毁清册、备份任务和四性检测记录；下游消费为档案列表筛选、领导查看工作情况和数据研判入口。页面不修改正式档案状态，不替代鉴定、销毁、审批或用户配置流程。

涉及状态节点：

- 正式档案：`normal`、`pending_shelf`、`pending_destruction`、`destroyed`
- 借阅申请：`applied`、`approved`、`checked_out`、`returned`、`overdue`
- 销毁清册：`draft`、`pending_approval`、`approved`、`destroyed`
- 备份任务：`running`、`success`、`failed`

## 3. 用户与操作分析

角色一：档案管理员（后台）。

- 主路径：查看馆藏、移交、征集、借阅、销毁、保存等指标；点击卡片跳转并带入筛选条件。
- 异常路径：统计源表异常或汇总失败时，查看统计时间和失败提示。

角色二：馆领导。

- 主路径：查看馆藏总量、本月新增、销毁审批相关统计和趋势图。
- 异常路径：无业务执行权限时只展示只读统计入口，不显示处理按钮。

## 4. 页面布局说明

页面使用管理后台统一壳层。内容区分为统计口径提示、时间筛选、核心指标卡、趋势分布图、业务统计表和数据源状态。

关键区域：

- 核心指标：馆藏总量、本月新增、待入库/待上架、借阅和销毁指标
- 图表区：按年度进馆数量、档案门类分布、纸电载体分布
- 明细汇总：移交/征集、借阅、销毁、保存检测指标
- 数据源：展示统计来自正式业务表和最近汇总时间

## 5. 交互逻辑说明

用户切换时间范围后刷新页面示例指标；点击指标卡时模拟跳转提示，显示目标页面和筛选条件；点击“导出统计表”模拟导出当前口径。图表使用静态柱状条和分布条，不写入任何业务表。

统计口径在页面内明确标注：馆藏来自 `archives`，移交/征集来自 `intake_batches`，借阅来自 `borrow_requests`，销毁来自 `destruction_lists`，保存来自 `backup_tasks` 和 `file_check_records`。

## 6. 启发式自查记录

1. 系统状态可见性：统计时间、数据源状态和卡片指标清晰可见。
2. 系统与现实世界匹配：使用馆藏、移交、征集、借阅、销毁、保存等业务术语。
3. 用户控制与自由：时间范围和分类筛选可调整，导出不影响业务数据。
4. 一致性与标准：复用后台壳层、指标卡、表格和状态标签。
5. 错误预防：页面只读，避免误把统计页作为业务处理入口。
6. 识别而非记忆：每个指标展示来源表和筛选含义。
7. 灵活性与效率：卡片可作为带条件跳转入口。
8. 美观与简约设计：统计、趋势、明细分区展示。
9. 帮助用户识别和修复错误：数据源异常时预留失败提示位置。
10. 帮助与文档：统计口径在页面显式呈现，便于核对。
