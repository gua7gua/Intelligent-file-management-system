# 管理概览 - 原型设计

## 1. 页面概述

- 页面名称：管理概览
- 所属门户：管理后台
- 页面路径：`prototype/admin/overview.html`
- 使用角色：前台管理员、后台管理员、馆领导、系统管理员
- 页面目标：展示按当前角色过滤的统计卡片、待办提醒、风险告警和最近操作日志，作为后台入口页。

## 2. 业务场景归属分析

所属业务场景为场景十六“管理员查看后台概览”。页面只做入口、提醒和汇总，不直接执行审批、销毁或批量修改。

涉及数据实体：
- `archives`、`intake_batches`、`intake_items`、`borrow_requests`、`approval_requests`、`destruction_lists`、`backup_tasks`、`audit_logs`、`system_configs`。

上下游关系：
- 上游：统一登录页按角色进入后台。
- 下游：移交验收、待入库与上架、档案管理、借阅审批、鉴定、销毁、审批、保存、用户管理和系统配置。

状态节点：
- 待验收、待入库、待上架、待审批、待销毁、到期提醒、存储空间告警。

## 3. 用户与操作分析

| 角色 | 操作 | 结果 |
|------|------|------|
| 前台管理员 | 查看待验收清单、待出库/归还借阅 | 跳转验收或借阅审批页面 |
| 后台管理员 | 查看待入库、待上架、到期鉴定、待销毁清册 | 跳转入库、鉴定、销毁页面 |
| 馆领导 | 查看待审批事项 | 跳转审批工作台 |
| 系统管理员 | 查看用户异常、存储和配置提醒 | 跳转用户管理或系统配置 |

## 4. 页面布局说明

- 后台壳层和统一导航。
- 顶部角色切换模拟不同角色的入口可见性。
- 统计卡片展示馆藏总量、本月新增、待入库、待审批、待销毁、存储空间。
- 待办列表按模块分组，点击跳转目标页面并保留筛选意图。
- 最近操作日志展示操作人、模块、操作和时间。

## 5. 交互逻辑说明

- 点击待办项跳转对应页面路径。
- 切换角色后提示“入口按后端权限过滤”，不把前端隐藏作为安全边界。
- 存储空间达到 85% 线时显示告警。
- 概览页不提供直接审批或销毁按钮。

## 6. 启发式自查记录

| 原则 | 自查结论 |
|------|----------|
| 系统状态可见性 | 指标、告警和待办状态可见。 |
| 现实世界匹配 | 使用待验收、待入库、待审批、到期提醒等业务语言。 |
| 用户控制与自由 | 入口均为跳转，不在概览直接执行危险操作。 |
| 一致性与标准 | 后台壳层、卡片、表格、状态标签一致。 |
| 错误预防 | 明确前端入口不是安全边界。 |
| 识别而非记忆 | 每个待办显示目标模块和状态。 |
| 灵活性与效率 | 卡片和待办可直达业务页面。 |
| 美观与简约 | 概览聚焦工作入口和风险提醒。 |
| 错误识别与恢复 | 告警给出跳转处理入口。 |
| 帮助与文档 | 说明概览页只做汇总不直接审批销毁。 |
