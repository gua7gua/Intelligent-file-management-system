# 全宗管理 - 原型设计

## 1. 页面概述

- 页面名称：全宗管理
- 所属门户：管理后台
- 页面路径：`prototype/admin/fonds.html`
- 使用角色：档案管理员（后台）、系统管理员
- 设计依据：`prototype/原型交互设计规范.md`、`new-doc/业务场景.md` 场景十八、`new-doc/数据库设计.md` 中 `fonds`、`organizations`、`archives`、`archive_boxes`。

## 2. 业务场景归属分析

本页面属于“全宗管理”场景，服务于档案馆接管新来源单位档案前后的基础数据维护。后台管理员先在本页建立全宗，并关联已录入的组织单位；后续“待入库与上架”页面在确认正式档案入库时选择全宗，写入 `archives.fonds_id`。系统管理员可辅助维护组织与全宗关系，但不替代档案业务判断。

上游输入为 `organizations` 中处于启用状态的组织单位，以及既有档案馆全宗编号体系。页面内维护 `fonds.fonds_no`、`fonds.fonds_name`、`fonds.organization_id`、`fonds.description`，并展示 `archives` 与 `archive_boxes` 聚合出的归档数量和档案盒数量。下游消费为档案入库、库房盒位、内部查阅数据范围过滤、档案管理检索和统计研判。

涉及状态节点：

- 组织状态：`active`、`disabled`
- 全宗维护状态：新建、编辑、停用
- 关联数据状态：有归档档案、有档案盒、无关联数据
- 审计节点：全宗新建、名称修改、所属单位修改、说明修改、停用均写入 `audit_logs`

## 3. 用户与操作分析

角色：档案管理员（后台）。

主路径操作：

- 查看全宗列表，按关键词、所属单位、是否有关联档案筛选
- 新建全宗，手动填写唯一全宗号、全宗名称、所属单位和全宗说明
- 编辑已有全宗的名称、所属单位和说明
- 查看全宗详情中的归档档案数量、档案盒数量、门类分布和最近入库记录
- 停用已有数据关联的全宗，避免继续被入库页面选择

异常路径操作：

- 全宗号为空或重复：阻止保存并提示全宗号唯一约束
- 未选择所属单位：阻止保存并提示必须关联组织单位
- 编辑时尝试修改全宗号：输入框只读并提示创建后不可修改
- 删除有关联档案或档案盒的全宗：阻止删除，提示只能停用

角色：系统管理员。

主路径操作：

- 查看全宗与组织单位绑定关系
- 辅助维护全宗基础信息和停用状态
- 确认组织单位缺失时跳转用户管理补齐组织数据

异常路径操作：

- 尝试越过后端权限直接访问档案正文：页面提示系统管理员不默认拥有档案正文查看权限
- 所属单位为禁用状态：保存时提示先启用或更换组织单位

## 4. 页面布局说明

页面使用管理后台统一壳层。内容区由顶部工具栏、统计概览、筛选区、全宗列表、详情编辑区和业务规则提示组成。

关键区域：

- 统计概览：展示全宗总数、启用全宗、归档档案量和档案盒数量
- 筛选区：支持关键词、所属单位和关联状态筛选
- 全宗列表：展示全宗号、全宗名称、所属单位、归档档案数量、档案盒数量、状态和操作
- 详情编辑区：新建或编辑全宗，保存前进行全宗号唯一和所属单位校验
- 分布与最近入库：帮助管理员判断该全宗是否已有业务数据关联
- 规则提示：说明全宗与移交清单不直接关联，入库时才写入正式档案归属

## 5. 交互逻辑说明

点击“新建全宗”清空表单，全宗号输入框可编辑；保存时校验全宗号、全宗名称和所属单位。点击列表“编辑”加载选中全宗，全宗号变为只读，名称、所属单位和说明可修改。点击“删除/停用”时，若归档档案数量或档案盒数量大于 0，页面阻止删除并改为停用确认；若无关联数据，原型模拟可删除。

筛选操作只影响列表可见范围，不改变数据。选择列表行会刷新右侧详情、门类分布和最近入库记录。保存成功、校验失败、停用和跳转均通过页面提示反馈。页面明确权限边界：全宗管理只维护基础归属关系，不创建正式档案、不修改档号、不替代入库和审批流程。

## 6. 启发式自查记录

1. 系统状态可见性：统计卡、状态标签、保存提示和停用反馈均可见。
2. 系统与现实世界匹配：使用全宗号、全宗名称、所属单位、归档档案、档案盒等档案业务术语。
3. 用户控制与自由：新建、编辑可取消；危险操作前提示关联数据影响。
4. 一致性与标准：复用管理后台壳层、表格、按钮、状态标签和表单样式。
5. 错误预防：全宗号唯一、所属单位必填、全宗号只读、有关联数据不可删除。
6. 识别而非记忆：详情区展示当前选中全宗和关联数据，不要求用户记忆列表内容。
7. 灵活性与效率：提供关键词、单位和关联状态筛选，支持快速新建。
8. 美观与简约设计：列表、表单和规则提示分区，避免无关装饰。
9. 帮助用户识别和修复错误：校验失败明确指出全宗号重复或所属单位缺失。
10. 帮助与文档：页面内说明全宗与入库、档案盒和权限过滤的关系。
