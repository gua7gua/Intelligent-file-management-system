# 数据统计 - 验收

## 1. 验收范围

- 页面：数据统计
- 路径：`prototype/admin/statistics.html`
- 版本：静态高保真原型
- 验收依据：`数据统计-原型设计.md`、场景十二、场景十六、数据库表 `archives`、`intake_batches`、`borrow_requests`、`destruction_lists`、`backup_tasks`、`file_check_records`

## 2. 功能验收项

| 验收项 | 验收标准 | 状态 |
|---|---|---|
| 后台统一壳层 | 页面包含左侧导航、顶部栏和管理后台内容区 | 通过 |
| 公共样式引用 | HTML 引用 `../common/css/base.css`、`components.css`、`shell.css` | 通过 |
| 正式表统计口径 | 页面明确列出统计来源表，不维护单独统计库 | 通过 |
| 核心指标 | 展示馆藏总量、本月新增、待入库/待上架、待审批销毁清册 | 通过 |
| 业务汇总 | 展示移交、征集、借阅、销毁、保存检测等指标 | 通过 |
| 趋势与分布 | 展示年度进馆、门类分布和纸电载体分布 | 通过 |
| 只读边界 | 页面明确统计页不修改正式档案、不执行审批或销毁 | 通过 |

## 3. 交互验收项

| 验收项 | 验收标准 | 状态 |
|---|---|---|
| 时间范围切换 | 切换后点击刷新，指标按示例范围更新并提示来源表不变 | 通过 |
| 卡片跳转 | 点击核心指标卡，模拟展示目标页面和筛选条件 | 通过 |
| 导出统计 | 点击导出后生成模拟导出反馈 | 通过 |
| 数据源状态 | 页面展示各来源表状态和最近汇总时间 | 通过 |

## 4. 启发式评估验收

1. 系统状态可见性：刷新时间、来源表状态和指标变化可见，符合。
2. 系统与现实世界匹配：指标按档案业务域组织，符合。
3. 用户控制与自由：时间范围可切换，导出不影响业务数据，符合。
4. 一致性与标准：复用后台壳层、指标卡和状态标签，符合。
5. 错误预防：统计页只读，避免误操作业务状态，符合。
6. 识别而非记忆：每个业务域展示来源表和口径，符合。
7. 灵活性与效率：卡片可模拟带筛选条件跳转，符合。
8. 美观与简约设计：指标、趋势、明细和来源分区清楚，符合。
9. 帮助用户识别和修复错误：数据源状态区预留异常提示，符合。
10. 帮助与文档：统计口径说明在页面中可见，符合。

## 5. 问题记录

无阻断问题。静态图表为 CSS 模拟，后续实现需接入正式统计接口或定时汇总接口。

## 6. 验收结论

通过。页面满足“统计来自正式业务表、统计页只读”的业务口径，可作为馆藏与业务运行统计入口。
