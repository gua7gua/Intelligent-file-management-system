# 系统配置 - 验收

## 1. 验收范围

- 页面：系统配置
- 路径：`prototype/admin/system-settings.html`
- 版本：静态高保真原型
- 验收依据：`系统配置-原型设计.md`、场景十四、数据库表 `system_configs`、`audit_logs`

## 2. 功能验收项

| 验收项 | 验收标准 | 状态 |
|---|---|---|
| 后台统一壳层 | 页面包含左侧导航、顶部栏和管理后台内容区 | 通过 |
| 公共样式引用 | HTML 引用 `../common/css/base.css`、`components.css`、`shell.css` | 通过 |
| 文件白名单 | 展示并支持新增上传格式白名单 | 通过 |
| 上传大小 | 展示并支持维护最大上传大小 MB | 通过 |
| AI 开关 | 支持启停 `ai.enabled` 并提示 AI 不是主流程依赖 | 通过 |
| 公开检索开关 | 支持启停 `public_search.enabled` 并提示不改变档案公开字段 | 通过 |
| 业务参数 | 展示库房占用阈值、默认借阅天数和征集捐赠协议文案 | 通过 |
| 审批边界 | 明确配置页不办理密级、开放、销毁审批 | 通过 |

## 3. 交互验收项

| 验收项 | 验收标准 | 状态 |
|---|---|---|
| 新增格式 | 输入扩展名后点击添加，白名单新增标签 | 通过 |
| 保存配置 | 保存时校验上传大小和默认借阅天数范围 | 通过 |
| AI 开关 | 切换后概览指标同步显示开/关并提示影响 | 通过 |
| 公开检索开关 | 切换后概览指标同步显示开/关并提示不改正式档案字段 | 通过 |
| 恢复示例值 | 点击后恢复页面示例配置 | 通过 |

## 4. 启发式评估验收

1. 系统状态可见性：开关状态、配置值和最近保存时间清楚，符合。
2. 系统与现实世界匹配：使用上传白名单、公开检索、借阅天数等业务语言，符合。
3. 用户控制与自由：保存前可编辑，恢复示例值可回退，符合。
4. 一致性与标准：复用后台壳层、表单、表格和状态标签，符合。
5. 错误预防：上传大小和借阅天数保存前校验，符合。
6. 识别而非记忆：配置键、当前值、类型和说明同屏展示，符合。
7. 灵活性与效率：支持快速新增格式和启停开关，符合。
8. 美观与简约设计：上传、能力、业务参数和协议文案分区清楚，符合。
9. 帮助用户识别和修复错误：数值越界时给出具体原因，符合。
10. 帮助与文档：审批边界、审计要求和 AI 依赖边界均有提示，符合。

## 5. 问题记录

无阻断问题。静态原型中的配置保存为前端模拟，后续实现需接入配置和审计接口。

## 6. 验收结论

通过。页面满足“系统配置服务系统管理员，不替代档案业务审批”的业务边界。
