# 库房管理 - 原型设计

## 1. 页面概述

- 页面名称：库房管理
- 所属门户：管理后台
- 页面路径：`prototype/admin/warehouse.html`
- 使用角色：档案管理员（后台）
- 页面目标：维护库房房间、机架、层、盒位结构，展示盒位占用率、告警阈值和纸质档案架位编码。

## 2. 业务场景归属分析

- 所属业务场景：`new-doc/业务场景.md` 场景六“库房管理”。
- 上游关系：待入库与上架页面在纸质相关档案入库时需要选择档案盒和架位；架位结构来自本页面生成的库房、机架、层、盒位。
- 下游关系：档案盘点按库房号和分类生成任务；借阅出库时管理员依据架位取件；销毁执行时按清册回库房核对实物。
- 涉及数据实体：`warehouse_rooms`、`storage_locations`、`archive_boxes`、`archive_box_items`、`archives`。
- 关键字段：`room_no`、`rack_count`、`layers_per_rack`、`boxes_per_layer`、`capacity`、`used_capacity`、`warning_threshold`、`location_code`、`status`、`current_box_id`。
- 状态节点：库房状态 `active/disabled`；架位状态 `empty/occupied/disabled`；档案盒状态 `normal/full/moved/destroyed`。
- PlantUML 校准：`warehouse-structure.puml` 明确结构为“库房/房间 -> 机架 -> 层 -> 盒位 -> 档案盒 -> 档案条目”，编码为“库房号-机架号-层号-盒位号”。

## 3. 用户与操作分析

- 档案管理员（后台）主路径操作：
  - 查看库房总容量、已占用盒位、告警库房和停用架位。
  - 新增库房，填写库房号、机架数量、单机架层数、每层最大盒数和告警阈值。
  - 提交新增后由系统按 `rack_count * layers_per_rack * boxes_per_layer` 生成架位结构。
  - 按库房、机架、状态筛选架位，查看 `401-03-02-05` 格式位置编码和当前档案盒。
  - 查看档案盒内条目和盒脊信息，辅助上架、盘点、借阅、销毁取件。
- 档案管理员（后台）异常路径操作：
  - 库房占用率达到或超过 85% 时显示告警。
  - 停用空架位；已占用架位不可直接停用。
  - 输入库房号重复、层数或盒位数为空时展示校验提示。
- 操作结果：
  - 新增库房触发库房与架位结构生成。
  - 筛选只改变列表展示，不改变业务状态。
  - 停用架位触发架位状态变更并写入审计日志。

## 4. 页面布局说明

- 统一后台左侧导航和顶部栏。
- 顶部标题区展示页面名称、业务说明和当前角色。
- 指标区展示库房数、总盒位、已占用盒位、告警库房。
- 主体左侧为库房列表和新增库房表单；右侧为架位矩阵、编码规则和盒位详情抽屉。
- 架位矩阵按机架和层聚合显示，颜色区分空闲、已占用、停用、告警。
- 下方表格展示最近占用盒位，包含库房号、位置编码、盒号、分类、全宗、状态。

## 5. 交互逻辑说明

- 点击“添加库房”打开页面内模拟弹窗；提交后显示“已生成架位结构”的状态提示。
- 表单中库房号用于生成编码前缀；机架号、层号、盒位号展示为两位补零，例如 `401-03-02-05`。
- 点击架位矩阵中的盒位卡片，右侧详情区展示当前位置、档案盒、盒内档案条目和可执行操作。
- 占用率达到告警阈值的库房在列表和指标卡中标为“容量告警”。
- 已占用架位的“停用”按钮置灰，提示需先迁出档案盒。

## 6. 启发式自查记录

1. 系统状态可见性：指标卡、占用率条和状态标签展示库房容量与架位状态。
2. 系统与现实世界匹配：使用库房、机架、层、盒位、档案盒等档案馆物理概念。
3. 用户控制与自由：新增表单提供取消；停用架位前展示限制说明。
4. 一致性与标准：沿用后台统一导航、按钮、状态标签和表格样式。
5. 错误预防：新增库房表单提示必填和编码示例；已占用架位不允许直接停用。
6. 识别而非记忆：页面显式展示编码规则和示例 `401-03-02-05`。
7. 灵活性与效率：支持按库房、机架、状态快速筛选。
8. 美观与简约设计：主体聚焦库房容量、架位矩阵和盒位详情，不展示无关档案正文。
9. 帮助用户识别、诊断并修复错误：重复库房号、容量配置不完整时给出中文提示。
10. 帮助与文档：编码规则和告警规则在页面内就近说明。
