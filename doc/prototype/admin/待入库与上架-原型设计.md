# 待入库与上架 - 原型设计

## 1. 页面概述

- 页面名称：待入库与上架
- 所属门户：管理后台
- 页面路径：`prototype/admin/pending-archive.html`
- 使用角色：档案管理员（后台）
- 页面目标：后台管理员处理已接收或部分接收清单中的已接收条目，批次级触发 AI 整批补全白名单字段，整批表单人工核查后生成正式档案和正式档号；纸质相关档案填写盒号、盒脊和架位，入库后处于已入库未上架，确认上架后进入正常利用范围。

## 2. 业务场景归属分析

- 所属业务场景：业务部门移交档案的“后台入库”阶段。
- 涉及数据实体：`intake_batches`、`intake_items`、`staging_files`、`archives`、`archive_files`、`archive_boxes`、`archive_box_items`、`archive_change_logs`。
- AI 相关实体字段：`intake_items.ai_suggestion`、确认后的题名、责任者、形成日期、分类、标签、摘要。
- 状态节点：
  - 清单批次：已接收/部分接收 -> 待入库 -> 已入库 -> 已上架。
  - 清单条目：已接收 -> 待入库 -> 已入库。
  - 暂存电子文件：匹配成功 -> 已归档。
  - 正式档案：纯电子入库后为正常；纸质+电子/纯纸质入库后为已入库未上架，上架后为正常。
- 上游关系：前台管理员在验收页面确认接收并上传暂存文件。
- 下游关系：正式档案进入档案管理、检索利用、借阅、盘点、鉴定等后续业务；纸质相关档案上架前不对查阅者和公众开放。
- 权限边界：后台管理员可执行 AI 整批补全、人工核查、入库、装盒、分配架位和上架；AI 不生成档号、不覆盖受保护字段。

## 3. 用户与操作分析

| 角色 | 操作 | 路径类型 | 结果 |
|------|------|----------|------|
| 档案管理员（后台） | 查看已接收/部分接收清单 | 主路径 | 查询待入库批次和条目 |
| 档案管理员（后台） | 点击 AI 整批补全 | 主路径 | AI 返回整批白名单字段 JSON，经后端过滤后展示候选 |
| 档案管理员（后台） | 人工确认或修改候选字段 | 主路径 | 条目状态变为待入库 |
| 档案管理员（后台） | 手工填写字段 | 降级路径 | AI 不可用时仍可完成入库 |
| 档案管理员（后台） | 填写盒号、盒脊、架位 | 主路径 | 纸质相关档案满足入库校验 |
| 档案管理员（后台） | 确认入库 | 主路径 | 生成正式档案、正式档号和正式电子文件记录 |
| 档案管理员（后台） | 确认上架 | 主路径 | 纸质相关档案状态从已入库未上架变为正常 |
| 档案管理员（后台） | 处理 AI 异常 | 异常路径 | 剥离或拒绝受保护字段，管理员手工处理 |

## 4. 页面布局说明

- 管理后台壳层：统一左侧导航和顶部栏。
- 内容区：
  - 阶段统计：待 AI 补全、待确认、待入库、待上架。
  - 批次列表：筛选已接收/部分接收批次。
  - 条目处理区：展示清单原始字段、AI 候选字段、人工确认字段。
  - AI JSON 面板：展示白名单结果和被剥离字段提示。
  - 入库与上架面板：按载体状态显示不同要求，纯电子无需架位，纸质相关必须填写盒号和架位。
  - 操作日志提示：记录 AI 确认、入库、上架等关键动作。

## 5. 交互逻辑说明

1. 选择待入库批次后展示已接收条目，回退条目不进入入库列表。
2. 点击“AI 整批补全”后展示 `<JSON>` 结果，仅包含题名、责任者、形成日期、分类、标签、摘要。
3. 若 AI 返回密级、保管期限、是否公开、是否允许数字化、档号、架位等字段，页面显示“已剥离受保护字段”提示。
4. 管理员确认候选字段后，条目进入待入库状态；也可直接手工填写。
5. 纯电子档案确认入库后生成正式档号，暂存文件转正式文件，正式档案进入正常状态。
6. 纸质+电子/纯纸质档案确认入库时必须填写盒号、盒脊和架位；入库后状态为已入库未上架。
7. 点击“确认上架”后，纸质相关档案变为正常，清单状态可更新为已上架。

## 6. 启发式自查记录

| 原则 | 自查结论 |
|------|----------|
| 系统状态可见性 | 待补全、待确认、待入库、待上架状态可见。 |
| 现实世界匹配 | 使用装盒、盒脊、架位、上架、档号等档案库房语言。 |
| 用户控制与自由 | AI 结果可修改或放弃，支持手工入库。 |
| 一致性与标准 | 状态流转与清单、条目、暂存文件、正式档案状态机一致。 |
| 错误预防 | 纸质相关档案入库前必须填写盒号和架位；AI 受保护字段剥离。 |
| 识别而非记忆 | 页面列出 AI 允许字段和受保护字段。 |
| 灵活性与效率 | 支持整批 AI 补全、逐条核查和整批入库。 |
| 美观与简约 | 主处理区聚焦条目、AI 候选和入库表单。 |
| 错误识别与恢复 | AI 异常、架位缺失、暂存文件未匹配均有提示。 |
| 帮助与文档 | 页面内说明纸质未上架前不可对查阅者和公众开放。 |
