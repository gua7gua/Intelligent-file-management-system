| 编号 | 验收项 | 验收标准 | 状态 |

## 3. 交互验收项

| 编号 | 验收项 | 验收标准 | 状态 |
|------|--------|----------|------|
| I-01 | 队列切换 | 点击申请队列后详情同步切换 | 通过 |
| I-01A | 列表过滤 | 点击状态标签后左侧申请列表实际更新，空状态显示提示 | 通过 |
| I-02 | 审批校验 | 盘点范围命中时阻止通过；拒绝需填写原因 | 通过 |
| I-03 | 出库校验 | 审批通过前不能确认出库 | 通过 |
| I-04 | 归还校验 | 未出库不能归还，异常归还需说明 | 通过 |
