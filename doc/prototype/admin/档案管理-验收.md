# 档案管理 - 验收

## 1. 验收范围

- 页面：档案管理
- 路径：`prototype/admin/archive-management.html`
- 版本：新版原型重建第 2 批

## 2. 功能验收项

| 编号 | 验收项 | 验收标准 | 状态 |
|------|--------|----------|------|
| F-01 | 分类树 | 展示文书、科技、会计、音像、人事五大固定门类 | 通过 |
| F-02 | 多条件筛选 | 支持关键词、年度、密级、开放、保管期限、载体筛选 | 通过 |
| F-03 | 元数据编辑 | 可编辑题名、责任者、形成日期、分类、标签、摘要 | 通过 |
| F-04 | 受保护字段 | 密级、保管期限、公开状态、允许数字化、档号、架位、销毁状态不可普通编辑 | 通过 |
| F-05 | 调整审批 | 密级/开放调整需凭证档号和理由，提交后进入审批工作台 | 通过 |
