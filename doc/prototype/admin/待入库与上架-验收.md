## 2. 功能验收项

| 编号 | 验收项 | 验收标准 | 状态 |
|------|--------|----------|------|
| F-01 | 待处理批次 | 展示已接收/部分接收批次，说明回退条目不入库且不占用档号 | 通过 |
| F-02 | AI 整批补全 | 批次级一次生成题名、责任者、形成日期、分类、标签、摘要白名单字段 | 通过 |
| F-03 | 受保护字段 | 页面列出密级、保管期限、公开状态、允许数字化、档号、架位等保护字段 | 通过 |
| F-04 | 整批人工确认 | 所有条目候选字段完整展示，可逐条修改后整批保存核查结果 | 通过 |
| F-05 | 入库校验 | 纸质+电子和纯纸质档案入库前必须填写盒号、盒脊和架位 | 通过 |
| F-06 | 上架边界 | 纸质相关档案入库后为已入库未上架，确认上架后才进入正常利用范围 | 通过 |
