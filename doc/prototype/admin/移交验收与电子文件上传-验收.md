# 移交验收与电子文件上传 - 验收

## 1. 验收范围

- 页面：移交验收与电子文件上传
- 路径：`prototype/admin/transfer-reception.html`
- 版本：静态高保真原型
- 验收依据：前台管理员调取清单、清点实物、上传 U 盘电子文件、文件名匹配、四性检查、回退条目和导出回执的业务口径。

## 2. 功能验收项

| 编号 | 功能点 | 验收标准 | 状态 |
|------|--------|----------|------|
| F-01 | 管理后台壳层 | 使用统一左侧导航和顶部栏 | 通过 |
| F-02 | 权限说明 | 明确前台只做验收、暂存文件和回执，不生成正式档号 | 通过 |
| F-03 | 待验收清单 | 展示待移交清单列表，可切换清单 | 通过 |
| F-04 | 清单详情 | 展示清单标题、单位、经办人、预计移交日期和签字清单状态 | 通过 |
| F-05 | U 盘上传 | 支持选择或拖拽文件，模拟写入暂存文件 | 通过 |
| F-06 | 文件名匹配 | 展示匹配成功、重复、多余、缺失等结果 | 通过 |
| F-07 | 条目验收 | 支持纸质核对、接收/回退结论和说明填写 | 通过 |
| F-08 | 回退原因 | 回退条目确认接收前必须填写原因 | 通过 |
| F-09 | 确认接收 | 全部处理后可模拟已接收或部分接收 | 通过 |
| F-10 | 回执导出 | 确认接收后可导出接收回执 | 通过 |
| F-11 | 滚动审查 | 左侧清单、右侧工作区、条目验收表格均可独立滚动 | 通过 |

## 3. 交互验收项

| 编号 | 交互点 | 验收标准 | 状态 |
|------|--------|----------|------|
| I-01 | 清单切换 | 点击左侧批次卡片后右侧详情、条目和回执同步切换 | 通过 |
| I-02 | 上传反馈 | 拖拽或选择文件后展示匹配结果和 toast 反馈 | 通过 |
| I-03 | 批量纸质通过 | 可批量标记纸质验收通过，但电子异常仍需处理 | 通过 |
| I-04 | 接收校验 | 存在待验收或回退原因缺失时阻止确认接收 | 通过 |
| I-05 | 回执状态 | 待处理条目清零后启用导出回执按钮 | 通过 |
| I-06 | 筛选标签 | “待移交 / 今日到馆 / 存在异常”筛选会实际更新左侧清单 | 通过 |

## 4. 启发式评估验收

| 原则 | 结论 |
|------|------|
| 系统状态可见性 | 批次、条目、文件匹配和回执状态清晰展示。 |
| 现实世界匹配 | 页面使用 U 盘、签字清单、接收回执、盖章等前台业务语言。 |
| 用户控制与自由 | 异常条目可人工处理或回退，确认前可修改说明。 |
| 一致性与标准 | 状态区分批次、条目和暂存文件，未混用正式档案状态。 |
| 错误预防 | 回退原因必填，异常文件不自动接收。 |
| 识别而非记忆 | 匹配卡片直接说明异常原因和处理方向。 |
| 灵活性与效率 | 支持批量纸质验收通过、批量文件上传、筛选标签和独立滚动审查。 |
| 美观与简约 | 页面按待验收清单、上传匹配、条目验收、回执预览组织。 |
| 错误识别与恢复 | 未匹配、重复、缺失、检查失败都有可见标签。 |
| 帮助与文档 | 页面提示前台与后台职责边界。 |

通过。页面覆盖前台管理员从待移交清单调取、纸质验收、电子文件暂存匹配、异常回退到回执导出的完整流程，并保持与后台入库职责分离。
