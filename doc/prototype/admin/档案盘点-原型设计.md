# 档案盘点 - 原型设计

## 1. 页面概述

- 页面名称：档案盘点
- 所属门户：管理后台
- 页面路径：`prototype/admin/inventory.html`
- 使用角色：档案管理员（后台）
- 页面目标：按库房号和档案分类创建盘点任务，生成盘点清单，记录正常、缺失、错位、损坏、借出中等结果，并在盘点期间暂停命中范围内档案借阅。

## 2. 业务场景归属分析

- 所属业务场景：`new-doc/业务场景.md` 场景七“盘点任务”。
- 上游关系：库房管理提供库房、架位和档案盒结构；正式档案上架后进入盘点范围。
- 下游关系：借阅审批需要检查进行中的盘点范围；盘点完成后档案从“盘点中/暂停借阅”恢复为正常可借；异常结果供后续修复、迁架或实体检查。
- 涉及数据实体：`inventory_tasks`、`inventory_items`、`warehouse_rooms`、`storage_locations`、`archive_boxes`、`archive_box_items`、`archives`。
- 关键字段：`task_no`、`task_name`、`room_id`、`category_id`、`status`、`started_at`、`completed_at`、`summary`、`expected_location_id`、`actual_location_code`、`check_result`、`note`。
- 状态节点：盘点任务 `draft/running/completed`；盘点明细 `normal/missing/misplaced/damaged/on_loan`；正式档案在盘点命中期间对应“盘点中/借阅暂停”。
- PlantUML 校准：`archive-state-machine.puml` 中正式档案 `Normal -> Inventorying -> Normal`；`business-flow-borrow.puml` 要求借阅审批检查档案状态、盘点范围和是否已借出。

## 3. 用户与操作分析

- 档案管理员（后台）主路径操作：
  - 查看进行中、草稿、已完成盘点任务数量和借阅暂停范围。
  - 新建盘点任务，选择库房号、分类、任务名称。
  - 系统按“库房号 AND 分类”生成盘点清单。
  - 按架位核对实物，标记正常、缺失、错位、损坏、借出中。
  - 填写异常说明并提交盘点结果。
- 档案管理员（后台）异常路径操作：
  - 任务创建时未选择库房号或分类则阻止生成。
  - 进行中任务命中范围内的借阅申请显示“盘点暂停借阅”。
  - 已借出档案不强制召回，在盘点清单中标为“借出中”。
- 操作结果：
  - 新建任务触发 `inventory_tasks` 创建，命中档案生成 `inventory_items`。
  - 盘点开始后命中范围内档案 `loan_status` 可置为 `suspended`。
  - 提交结果后任务变为 `completed`，正常档案恢复可借，异常项保留结果和说明。

## 4. 页面布局说明

- 统一后台左侧导航和顶部栏。
- 顶部指标区展示进行中任务、暂停借阅档案、异常项、已完成任务。
- 任务创建区突出库房号、分类和任务名称，显式标注筛选关系为 AND。
- 主体采用左右布局：左侧任务列表，右侧盘点清单与结果标记。
- 清单表格展示档号、题名、应在架位、实际架位、借阅状态、盘点结果、说明。
- 页面底部展示“借阅审批影响”提示，说明命中范围内借阅审批需拒绝或暂停。

## 5. 交互逻辑说明

- 点击“新建盘点任务”打开表单弹窗；选择库房号和分类后自动生成任务名称示例。
- 点击“生成清单”后任务进入进行中，页面显示“401 库房 AND 科技档案”范围条。
- 表格中结果按钮为单选语义，同一条明细只能选择一个结果。
- 选择“错位”时需要填写实际架位；选择“缺失/损坏”时需要填写说明。
- 点击“提交盘点结果”汇总正常、异常、借出中数量，并模拟任务完成反馈。

## 6. 启发式自查记录

1. 系统状态可见性：任务状态、暂停借阅数量、异常数量可见。
2. 系统与现实世界匹配：使用库房号、分类、架位、借出中、缺失、错位、损坏等业务术语。
3. 用户控制与自由：任务创建弹窗支持取消；清单结果可重新选择。
4. 一致性与标准：沿用统一后台导航、状态标签、按钮、表格和表单样式。
5. 错误预防：盘点范围必须同时选择库房号和分类；页面强调 AND 关系。
6. 识别而非记忆：当前任务范围在列表和清单顶部持续展示。
7. 灵活性与效率：支持按任务状态切换和按异常结果筛选。
8. 美观与简约设计：优先展示任务、范围、清单和结果，不展示无关正文。
9. 帮助用户识别、诊断并修复错误：异常项提供说明字段和实际架位字段。
10. 帮助与文档：借阅暂停规则在页面内以业务提示展示。
