# 审批工作台 - 原型设计

## 1. 页面概述

- 页面名称：审批工作台
- 所属门户：管理后台
- 页面路径：`prototype/admin/approval.html`
- 使用角色：馆领导
- 页面目标：集中处理密级调整、开放调整和销毁清册审批，查看目标档案、凭证档案或清册快照，填写审批意见并通过或退回。

## 2. 业务场景归属分析

- 所属业务场景：`new-doc/业务场景.md` 场景三“档案管理（整理、密级调整、开放调整）”和场景五“档案销毁”。
- 上游关系：档案管理详情页提交密级调整/开放调整审批；档案销毁页面提交销毁清册审批。
- 下游关系：密级或开放审批通过后更新目标档案字段并写变更日志；销毁审批通过后清册状态变为待销毁；审批退回时目标对象保持不变并保留退回意见。
- 涉及数据实体：`approval_requests`、`archives`、`destruction_lists`、`destruction_items`、`archive_change_logs`、`audit_logs`。
- 关键字段：`approval_type`、`target_type`、`target_id`、`target_archive_id`、`evidence_archive_id`、`old_value`、`new_value`、`reason`、`status`、`submitted_by`、`submitted_at`、`approved_by`、`approved_at`、`approval_opinion`。
- 状态节点：审批单 `pending -> approved/rejected`；密级/开放调整通过后写入档案变更；销毁清册通过后 `pending_approval -> approved`。
- PlantUML 校准：`business-flow-approval.puml` 要求凭证档号存在、未销毁、可被审批查看，凭证与目标档案来源关系匹配；馆领导在审批工作台查看目标档案和凭证档案。`business-flow-destruction.puml` 要求馆领导查看清册和鉴定结论后审批通过或退回。

## 3. 用户与操作分析

- 馆领导主路径操作：
  - 查看待审批数量、已批准数量、已退回数量和销毁审批数量。
  - 按审批类型筛选：密级调整、开放调整、销毁审批。
  - 打开审批单，查看申请理由、调整前后值、提交人和提交时间。
  - 密级/开放审批查看目标档案与凭证档案并列信息。
  - 销毁审批查看销毁清册快照、来源鉴定批次和鉴定意见。
  - 填写审批意见，点击审批通过或退回。
- 馆领导异常路径操作：
  - 凭证档案缺失、已销毁或来源关系不匹配时不可通过，只能退回。
  - 销毁清册缺少快照或鉴定结论时不可通过，只能退回补正。
  - 未填写审批意见时提示补充。
- 操作结果：
  - 审批通过写入 `approval_requests.status = approved`、审批人、时间和意见。
  - 密级/开放审批通过后由业务服务更新目标档案字段并写 `archive_change_logs`。
  - 销毁审批通过后清册状态变为 `approved`，在销毁页面进入待销毁。
  - 退回写入 `approval_requests.status = rejected`，目标档案或清册不变。

## 4. 页面布局说明

- 统一后台左侧导航和顶部栏，但顶部角色显示为馆领导。
- 顶部指标区展示待审批、今日已处理、销毁审批、退回补正。
- 主体左侧为审批队列和类型标签；右侧为审批详情。
- 详情上半部分展示审批单基础信息、申请理由、调整前后值和风险提示。
- 密级/开放审批以双栏展示目标档案和凭证档案；销毁审批展示清册快照表。
- 详情底部为审批意见、通过和退回按钮。

## 5. 交互逻辑说明

- 点击审批队列切换详情类型和右侧内容。
- 点击类型标签过滤队列激活态。
- “审批通过”前检查审批意见；通过后显示状态已批准，并说明业务字段生效或清册进入待销毁。
- “退回补正”前检查退回意见；退回后显示状态已退回，目标字段不变。
- 销毁审批详情明确提示馆领导审批即批准凭证，无第三方节点。

## 6. 启发式自查记录

1. 系统状态可见性：待审批、已批准、已退回、审批结果反馈可见。
2. 系统与现实世界匹配：使用馆领导审批、凭证档案、清册快照、退回补正等业务语言。
3. 用户控制与自由：审批意见提交前可修改；通过和退回分开。
4. 一致性与标准：复用后台导航、标签、表格、按钮和状态样式。
5. 错误预防：审批意见必填，凭证异常和清册证据不完整时提醒。
6. 识别而非记忆：目标档案、凭证档案和清册快照并列可见。
7. 灵活性与效率：按审批类型快速筛选和切换。
8. 美观与简约设计：审批详情只展示决策所需证据。
9. 帮助用户识别、诊断并修复错误：退回原因输入提示申请人需补正内容。
10. 帮助与文档：页面内说明审批通过后的业务结果。
