# 忘记密码页 - 原型设计

## 1. 页面概述

- 页面名称：忘记密码页
- 所属门户：公众门户
- 页面路径：`prototype/public/forgot-password.html`
- 设计依据：`prototype/原型生成计划.md` 第 0 批、`new-doc/业务场景.md` 场景十一、`new-doc/数据库设计.md` 用户表、`new-doc/技术架构.md` 短信服务可选口径

## 2. 业务场景归属分析

本页只用于社会公众账号找回密码。内部账号、移交单位经办人、管理员、馆领导和系统管理员的密码重置由系统管理员在用户管理中执行。

涉及数据实体与字段：
- `users`：`user_type = public`、`phone`、`password_hash`、`status`
- `audit_logs`：验证码发送、密码重置成功、重置失败
- `system_configs`：短信服务和验证码策略配置可作为扩展

上下游关系：
- 上游：统一登录页、公众注册页。
- 下游：密码重置成功后回到 `../login.html` 或进入公众概览。

状态节点：
- 验证码：待发送、已发送、校验通过、过期/错误
- 密码重置：待提交、重置成功、重置失败

## 3. 用户与操作分析

角色：
- 社会公众：输入手机号、验证码、新密码和确认密码，完成密码重置。

主路径操作：
- 输入公众手机号并发送验证码。
- 填写验证码和新密码，提交重置。
- 重置成功后返回统一登录页。

异常路径操作：
- 手机号不是公众账号：提示公众账号不存在或状态异常。
- 验证码为空/错误/过期：提示重新获取。
- 两次密码不一致：阻止提交。

## 4. 页面布局说明

采用公众顶部导航 + 单卡片表单：
- 左侧步骤条说明手机号验证、设置新密码、重新登录。
- 右侧表单执行验证码发送和密码重置。
- 页面底部提示内部账号重置边界。

## 5. 交互逻辑说明

- 发送验证码后显示“已发送”并模拟倒计时状态。
- 提交时校验手机号格式、验证码、新密码一致性。
- 成功后显示重置结果和登录页路径。
- 若需要内部账号密码重置，提示联系系统管理员。

## 6. 启发式自查记录

1. 系统状态可见性：验证码发送与重置结果即时反馈。
2. 现实世界匹配：使用手机号与短信验证码。
3. 用户控制与自由：可返回登录或注册。
4. 一致性与标准：复用公共公众导航和表单样式。
5. 错误预防：手机号格式和密码一致性校验。
6. 识别而非记忆：步骤条展示找回流程。
7. 灵活性与效率：示例验证码便于原型验证。
8. 美观与简约：仅保留找回密码必要信息。
9. 错误恢复：提示重新获取验证码或联系管理员。
10. 帮助与文档：说明本页不处理内部账号。
