# 公众首页-原型设计

## 1. 页面概述

- 页面名称：公众首页
- 所属门户：公众门户
- 页面路径：`prototype/public/index.html`
- 使用角色：未登录用户、社会公众
- 页面目标：提供公开馆藏概况、公开档案检索入口、公众登录注册入口和征集清单入口。

## 2. 业务场景归属分析

- 所属业务场景：场景十一“公众访问与查询公开档案”，并为场景二“社会征集与捐赠”和场景十七“公众用户查看概览”提供入口。
- 上游输入：公开统计由正式档案表汇总，口径限定为非密、公开、未销毁且生命周期为正常的正式档案。
- 下游消费：点击公开检索进入 `public/search.html`；点击公众概览进入 `public/overview.html`；点击征集清单进入 `public/collection.html`；登录和注册指向全局登录/公众注册页面。
- 涉及实体：`archives`、`archive_files`、`archive_access_logs`、`users`、`intake_batches`。
- 状态节点：正式档案仅展示 `lifecycle_status = normal` 且 `open_status = open` 的统计；不展示清单未接收、未入库、未上架或已销毁数据。

## 3. 用户与操作分析

- 未登录用户主路径：查看公开馆藏概况；进入公开档案检索；查看公开元数据；点击登录或注册。
- 未登录用户异常路径：尝试下载公开电子文件时引导登录；公开检索关闭时显示不可用提示。
- 社会公众主路径：进入公众概览；进入公开检索；进入征集清单；查看下载记录入口。
- 社会公众异常路径：若账号状态异常，概览入口提示登录状态需重新校验。
- 操作结果：页面跳转、公开检索入口跳转、公开统计查看；无状态变更。

## 4. 页面布局说明

- 顶部导航：档案馆名称、公众首页、公开检索、征集清单、公众概览、登录/注册按钮。
- 首屏内容：档案馆公开服务名称、公开检索主入口、馆藏公开统计卡片。
- 内容区：分类分布、最近公开批次、征集流程摘要、服务边界提示。
- 页脚信息：服务电话、开放时间和数据口径。

## 5. 交互逻辑说明

- 顶部导航使用公众门户独立顶部导航，不使用后台壳层。
- “公开检索”按钮跳转至 `search.html`，后端检索时强制追加非密、公开、正常/未销毁过滤条件。
- “提交征集清单”按钮跳转至 `collection.html`；征集清单只是捐赠意向登记，不上传文件本体。
- “登录”跳转至 `../login.html`，“注册”跳转至 `register.html`；下载电子文件由检索页在登录后执行。
- 统计和分类只展示聚合数字，不展示未公开档案题名、档号、架位或电子文件。

## 6. 启发式自查记录

1. 系统状态可见性：统计卡片、开放口径和服务状态在首屏可见。
2. 系统与现实世界匹配：使用“公开档案”“征集清单”“馆藏概况”等档案业务术语。
3. 用户控制与自由：导航可随时切换检索、征集、概览和登录注册。
4. 一致性与标准：复用公众顶部导航、卡片、按钮、状态标签等公共组件。
5. 错误预防：下载需登录、公开范围由后端过滤等边界在入口处明确。
6. 识别而非记忆：主要入口集中展示，用户无需记忆页面路径。
7. 灵活性与效率：首屏提供检索和征集两个高频入口。
8. 美观与简约设计：仅展示公开服务所需信息，不堆叠内部管理信息。
9. 帮助用户识别错误：公开检索关闭或下载未登录的异常由下游页面提示。
10. 帮助与文档：用服务边界和征集流程摘要说明公众可办理事项。
