# 公众注册页 - 原型设计

## 1. 页面概述

- 页面名称：公众注册页
- 所属门户：公众门户
- 页面路径：`prototype/public/register.html`
- 设计依据：`new-doc/业务场景.md` 场景十一、场景十七；`new-doc/数据库设计.md` 用户与角色表；`new-doc/puml/module-portal-overview.puml`

## 2. 业务场景归属分析

本页服务社会公众自注册账号，注册成功后写入 `users.user_type = public`，并关联 `public_user` 角色。内部用户、移交单位经办人、管理员、馆领导和系统管理员不通过本页创建账号。

涉及数据实体与字段：
- `users`：`login_name`、`phone`、`password_hash`、`real_name`、`user_type = public`、`status = active`
- `roles`、`user_roles`：默认关联 `public_user`
- `audit_logs`：注册成功、验证码校验失败等操作记录

上下游关系：
- 上游：公众首页或统一登录页。
- 下游：注册成功后进入 `public/overview.html`；也可跳转登录页。
- 并列功能：忘记密码页只处理公众账号找回。

状态节点：
- 验证码：未发送、已发送、校验通过、校验失败
- 公众账号：待提交、注册成功、注册失败

## 3. 用户与操作分析

角色：
- 社会公众：填写姓名、手机号、验证码、密码和确认密码，阅读公开利用与征集说明，提交注册。

主路径操作：
- 输入手机号并点击发送验证码。
- 填写验证码和密码，勾选确认说明，点击「创建公众账号」。
- 注册成功后跳转公众概览。

异常路径操作：
- 手机号格式错误、验证码为空、密码不一致、未勾选说明时阻止提交并提示。
- 发现自己已有账号时跳转统一登录页。

## 4. 页面布局说明

采用公众门户顶部导航 + 认证卡片布局：
- 顶部导航包含公众首页、公开检索、登录入口。
- 内容区左侧展示公众账号能力和边界，右侧展示注册表单。
- 表单字段与提示保持紧凑，突出手机号验证码和密码一致性。

## 5. 交互逻辑说明

- 发送验证码按钮模拟倒计时状态。
- 提交时校验手机号、验证码、密码一致性和确认勾选。
- 成功后显示账号创建结果、默认角色和目标跳转路径。
- 页面强调公众账号只能查看公开档案和本人征集/下载记录。

## 6. 启发式自查记录

1. 系统状态可见性：验证码发送、注册成功/失败提示可见。
2. 现实世界匹配：使用手机号、验证码、姓名等公众熟悉字段。
3. 用户控制与自由：可返回登录或公众首页。
4. 一致性与标准：复用公共按钮、表单和提示样式。
5. 错误预防：手机号格式、密码一致性和确认勾选校验。
6. 识别而非记忆：页面列出公众账号能力和限制。
7. 灵活性与效率：示例表单帮助快速体验原型。
8. 美观与简约：只保留注册必要字段。
9. 错误恢复：逐项提示修正原因。
10. 帮助与文档：说明内部账号由系统管理员维护。
