# 公众首页-验收

## 1. 验收范围

- 页面：公众首页
- 路径：`prototype/public/index.html`
- 对应设计文档：`prototype/public/公众首页-原型设计.md`
- 验收版本：静态 HTML 原型首版

## 2. 功能验收项

| 功能点 | 验收标准 | 状态 |
|--------|----------|------|
| 公众顶部导航 | 显示公众首页、公开检索、征集清单、公众概览、登录、注册入口 | 通过 |
| 公开馆藏统计 | 只展示非密、公开、未销毁正式档案的聚合统计口径 | 通过 |
| 快速检索入口 | 输入关键词后跳转到 `search.html?keyword=...`，空关键词跳转 `search.html` | 通过 |
| 征集入口 | “提交征集清单”跳转 `collection.html` | 通过 |
| 登录注册入口 | 登录指向 `../login.html`，注册指向 `register.html` | 通过 |
| 公开批次展示 | 只展示批次级公开信息，不展示未公开档案明细 | 通过 |

## 3. 交互验收项

| 交互项 | 验收标准 | 状态 |
|--------|----------|------|
| 导航高亮 | 当前页“智能档案馆”处于 active 状态 | 通过 |
| 按钮跳转 | 主按钮均为明确页面跳转，不触发未定义状态变更 | 通过 |
| 快速检索 | 表单提交通过 JavaScript 构造公开检索页 URL | 通过 |
| 响应式布局 | 首屏、统计卡片、分类区在窄屏下改为单列 | 通过 |
| 下载边界 | 页面文案明确下载需登录并重新鉴权，不在首页直接下载 | 通过 |

## 4. 启发式评估验收

1. 系统状态可见性：公开服务状态、统计口径和最近公开批次可见，符合。
2. 系统与现实世界匹配：使用档案馆公开服务语汇，符合。
3. 用户控制与自由：顶部导航可返回或切换核心任务，符合。
4. 一致性与标准：复用公共 CSS 的按钮、卡片、表格和状态标签，符合。
5. 错误预防：下载登录要求和公开范围过滤边界可见，符合。
6. 识别而非记忆：检索、征集、概览入口直接展示，符合。
7. 灵活性与效率：快速检索支持首屏直达检索页，符合。
8. 美观与简约设计：页面只展示公众入口和公开统计，符合。
9. 帮助用户识别、诊断并修复错误：复杂错误由检索和登录页面承接，本页无阻断错误，符合。
10. 帮助与文档：征集流程摘要提供办理上下文，符合。
