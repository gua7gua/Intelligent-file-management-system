# 征集清单-验收

## 1. 验收范围

- 页面：征集清单
- 路径：`prototype/public/collection.html`
- 对应设计文档：`prototype/public/征集清单-原型设计.md`
- 验收版本：静态 HTML 原型首版

## 2. 功能验收项

| 功能点 | 验收标准 | 状态 |
|--------|----------|------|
| 清单信息填写 | 支持清单标题、捐赠人、联系电话、捐赠说明 | 通过 |
| 条目维护 | 支持新增、删除、编辑档案标题、页数、载体状态、格式、文件名、形成日期 | 通过 |
| 文件名解析 | 文件选择或拖拽仅解析文件名、扩展名和大小，不上传文件本体 | 通过 |
| 目标属性展示 | 明确征集目标为永久、无密级、公开，且入库后才公开生效 | 通过 |
| 数量限制展示 | 显示待处理清单 5 个、单清单 200 条目的限制口径 | 通过 |
| 提交状态 | 提交后状态变为待联系，表单进入只读锁定 | 通过 |

## 3. 交互验收项

| 交互项 | 验收标准 | 状态 |
|--------|----------|------|
| 导航高亮 | 顶部导航“征集清单”处于 active 状态 | 通过 |
| 手工新增 | 点击新增条目后表格增加一行并更新数量 | 通过 |
| 删除条目 | 点击删除后移除当前行并更新数量 | 通过 |
| 保存草稿 | 保存草稿只显示反馈，不进入后台联系流程 | 通过 |
| 提交校验 | 无条目时阻止提交并提示 | 通过 |
| 提交锁定 | 提交后禁用表单控件，符合提交后不可编辑规则 | 通过 |

## 4. 启发式评估验收

1. 系统状态可见性：草稿、待联系状态和条目数量可见，符合。
2. 系统与现实世界匹配：字段名称与捐赠清单一致，符合。
3. 用户控制与自由：提交前可保存、编辑、删除条目，符合。
4. 一致性与标准：复用公共表单、表格、按钮、提示样式，符合。
5. 错误预防：不上传文件本体、提交后只读、无条目阻止提交，符合。
6. 识别而非记忆：目标属性和流程状态在右侧常驻，符合。
7. 灵活性与效率：支持批量文件名解析和手工录入，符合。
8. 美观与简约设计：页面不展示后台验收、AI 入库等非公众任务，符合。
9. 帮助用户识别、诊断并修复错误：无条目提交有明确反馈，符合。
10. 帮助与文档：边界说明聚焦征集办理，符合。
