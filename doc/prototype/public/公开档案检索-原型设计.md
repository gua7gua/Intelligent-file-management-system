# 公开档案检索-原型设计

## 1. 页面概述

- 页面名称：公开档案检索
- 所属门户：公众门户
- 页面路径：`prototype/public/search.html`
- 使用角色：未登录用户、社会公众
- 页面目标：提供面向公众的公开档案元数据检索、详情查看、在线预览和登录后下载入口；结构化条件覆盖公开可见的档号、题名、责任者、门类、标签、年度范围、来源、载体和电子文件属性。

## 2. 业务场景归属分析

- 所属业务场景：场景十一“公众访问与查询公开档案”。
- 上游输入：公众自然语言、结构化检索条件、登录状态。
- 下游消费：公开检索接口固定查询非密、公开、正常/未销毁正式档案；下载写入 `archive_access_logs`，未登录下载引导登录。
- 涉及实体：`archives`、`archive_files`、`archive_access_logs`、`users`。
- 状态节点：只展示 `security_level = 0`、`open_status = open`、`lifecycle_status = normal` 的正式档案；已销毁、未上架、未公开和涉密档案不返回。

## 3. 用户与操作分析

- 未登录用户主路径：输入公开检索条件；查看公开元数据；在线预览可公开文件。
- 未登录用户异常路径：点击下载时引导登录；公开检索关闭时提示不可用。
- 社会公众主路径：使用 AI 生成 JSON；填充表单；确认检索；查看详情；下载电子文件并记录日志。
- 操作结果：查询、详情展示、登录跳转、下载日志模拟；不显示架位，不提供借阅申请。

## 4. 页面布局说明

- 顶部导航：公众门户统一顶部导航，当前页高亮“公开检索”。
- 查询区：公开范围提示、AI 自然语言输入、JSON 结果、分组结构化检索条件；不提供内部密级范围、库房、盒号和审批字段。
- 结果区：公开档案元数据列表，展示题名、档号、分类、年度、载体和文件状态。
- 结果表格和详情区支持独立滚动，方便审查长列表和下载边界。
- 详情区：公开元数据、预览/下载操作和登录状态提示。

## 5. 交互逻辑说明

- AI 点击“生成 JSON”仅输出查询条件，并包含公开范围条件，不直接检索。
- “填充表单”将 JSON 字段写入关键词、档号、题名、分类、年度范围、责任者、标签、来源、载体状态、电子文件和排序等字段。
- “确认检索”模拟普通公开检索接口，后端强制追加非密、公开、正常/未销毁过滤条件。
- 未登录点击下载提示登录；切换为“已登录公众”后可模拟下载并记录日志。
- 页面不展示未公开档案题名、具体架位或内部密级范围。

## 6. 启发式自查记录

1. 系统状态可见性：登录状态、公开过滤条件、检索结果状态可见。
2. 系统与现实世界匹配：使用公开档案、档案门类、形成年度等公众可理解术语。
3. 用户控制与自由：AI JSON 可确认、填充、手工调整。
4. 一致性与标准：复用公众导航、表单、按钮、表格、状态标签。
5. 错误预防：下载需登录，公开范围由后端强制过滤。
6. 识别而非记忆：公开范围提示和条件表单同屏展示。
7. 灵活性与效率：支持自然语言、公开高级条件检索和长列表独立滚动。
8. 美观与简约设计：仅展示公开利用必要信息。
9. 帮助用户识别错误：未登录下载、不可下载文件均有提示。
10. 帮助与文档：页面说明 AI 不查库、不读取正文、不绕过公开范围。
