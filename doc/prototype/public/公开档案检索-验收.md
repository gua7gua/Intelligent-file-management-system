# 公开档案检索 - 验收

## 1. 验收范围

- 页面：公开档案检索
- 路径：`prototype/public/search.html`
- 版本：新版原型重建第 4 批

## 2. 功能验收项

| 编号 | 验收项 | 验收标准 | 状态 |
|------|--------|----------|------|
| F-01 | 公开范围 | 页面明确仅检索非密、公开、正常且未销毁的正式档案 | 通过 |
| F-02 | AI JSON | AI 只生成查询条件 JSON，不执行检索、不读取正文 | 通过 |
| F-03 | 条件填充 | JSON 可填充关键词、档号、题名、门类、年度范围、责任者、标签、来源、载体、电子文件状态等表单字段 | 通过 |
| F-04 | 结果列表 | 列表只展示公开元数据，不展示库房架位和内部密级范围 | 通过 |
| F-05 | 下载边界 | 未登录点击下载提示登录；已登录公众可模拟下载并记录日志 | 通过 |
| F-06 | 高级公开条件 | 表单只展示公众可用公开元数据条件，不提供内部密级、库房、盒号和审批字段 | 通过 |

## 3. 交互验收项

| 编号 | 验收项 | 验收标准 | 状态 |
|------|--------|----------|------|
| I-01 | 登录状态切换 | 未登录/已登录公众状态可切换并影响下载提示 | 通过 |
| I-02 | 详情切换 | 点击结果详情后右侧公开元数据更新 | 通过 |
| I-03 | JSON 生成与清空 | 生成、填充、复制和清空操作有反馈 | 通过 |
| I-04 | 不可下载提示 | 仅公开元数据档案点击下载时给出原因 | 通过 |
| I-05 | 独立滚动 | 公开结果表格和详情栏支持独立滚动，不遮挡登录下载状态 | 通过 |

## 4. 启发式评估验收

| 原则 | 评估结论 | 状态 |
|------|----------|------|
| 系统状态可见性 | 登录状态、结果范围、Toast 反馈可见 | 通过 |
| 现实世界匹配 | 使用公开档案、档案门类、形成年度等术语 | 通过 |
| 用户控制与自由 | AI 条件可填充、清空、手动调整 | 通过 |
| 一致性与标准 | 复用公众导航、查询表单、状态标签 | 通过 |
| 错误预防 | 下载需登录，公开范围由后端强制追加 | 通过 |
| 识别而非记忆 | 公开利用边界在详情旁展示 | 通过 |
| 灵活性与效率 | 支持自然语言、分组高级检索和长列表滚动 | 通过 |
| 美观与简约 | 页面只展示公众可用信息 | 通过 |
| 错误识别与恢复 | 未登录、无电子文件均给出明确提示 | 通过 |
| 帮助与文档 | 页面说明 AI 与公开过滤边界 | 通过 |
