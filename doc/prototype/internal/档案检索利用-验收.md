# 档案检索利用-验收

## 1. 验收范围

- 页面：档案检索利用
- 路径：`prototype/internal/search.html`
- 对应设计文档：`prototype/internal/档案检索利用-原型设计.md`
- 验收版本：静态 HTML 原型首版

## 2. 功能验收项

| 功能点 | 验收标准 | 状态 |
|--------|----------|------|
| 内部壳层 | 页面使用内部查阅者门户左侧导航、顶部栏、内容区布局 | 通过 |
| AI JSON 生成 | AI 区只生成查询条件 JSON，不执行检索 | 通过 |
| 表单填充 | 可将 JSON 条件填入结构化检索表单 | 通过 |
| 高级字段 | 结构化检索覆盖档号、题名、责任者、全宗、单位、标签、来源、载体、保管期限、密级、借阅状态和电子文件属性 | 通过 |
| 权限检索 | 确认检索提示后端按密级、单位、全宗范围过滤 | 通过 |
| 结果展示 | 展示题名、档号、分类、密级、载体和利用状态 | 通过 |
| 详情展示 | 详情区展示元数据、电子利用状态和借阅能力 | 通过 |
| 预览下载 | 预览和下载均模拟重新鉴权并记录日志 | 通过 |
| 借阅申请 | 可对纸质相关档案提交待审批借阅申请 | 通过 |

## 3. 交互验收项

| 交互项 | 验收标准 | 状态 |
|--------|----------|------|
| 导航高亮 | 左侧导航“档案检索利用”高亮 | 通过 |
| AI 不查库 | 生成 JSON 后需点击确认检索才模拟查询 | 通过 |
| JSON 填充 | 未生成 JSON 时填充会提示先生成 | 通过 |
| 结果详情 | 点击不同结果可刷新详情区 | 通过 |
| 纯电子借阅限制 | 纯电子档案点击借阅提示不支持纸质借阅 | 通过 |
| 纯纸质下载限制 | 纯纸质档案下载提示无可下载电子文件 | 通过 |
| 架位隐藏 | 页面未展示具体库房架位、盒位信息 | 通过 |
| 独立滚动 | 结果表格和右侧详情区具备独立滚动，长结果不遮挡借阅表单 | 通过 |

## 4. 启发式评估验收

1. 系统状态可见性：AI JSON、检索结果、详情和借阅申请状态可见，符合。
2. 系统与现实世界匹配：使用档案业务字段和借阅流程术语，符合。
3. 用户控制与自由：AI 输出可人工确认和调整，符合。
4. 一致性与标准：复用内部壳层、表单、表格、抽屉和标签，符合。
5. 错误预防：AI 不查库、不读正文、不绕过权限，不显示架位，符合。
6. 识别而非记忆：JSON 和结构化条件并列呈现，符合。
7. 灵活性与效率：支持自然语言生成条件、分组高级筛选和结果/详情独立滚动，符合。
8. 美观与简约设计：结果列聚焦查阅利用，不暴露管理员信息，符合。
9. 帮助用户识别、诊断并修复错误：不可下载、不可借阅均有提示，符合。
10. 帮助与文档：安全边界提示明确，符合。
