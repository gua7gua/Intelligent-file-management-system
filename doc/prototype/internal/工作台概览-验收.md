# 工作台概览-验收

## 1. 验收范围

- 页面：工作台概览
- 路径：`prototype/internal/overview.html`
- 对应设计文档：`prototype/internal/工作台概览-原型设计.md`
- 验收版本：静态 HTML 原型首版

## 2. 功能验收项

| 功能点 | 验收标准 | 状态 |
|--------|----------|------|
| 内部壳层 | 页面使用内部查阅者门户左侧导航、顶部栏、内容区布局 | 通过 |
| 个人指标 | 展示最近查阅、待审批、已批准待取件、下载记录 | 通过 |
| 最近查阅 | 展示当前用户最近查阅记录，并提示重新鉴权 | 通过 |

| 凭证导出 | 已批准未出库申请可模拟导出借阅凭证 | 通过 |
| 下载记录 | 展示当前用户下载记录摘要 | 通过 |
| 权限范围 | 展示角色、所属单位、密级上限和可见范围 | 通过 |

## 3. 交互验收项

| 交互项 | 验收标准 | 状态 |
|--------|----------|------|
| 导航高亮 | 左侧导航“工作台概览”高亮 | 通过 |
| 继续查看 | 通过记录提示可进入详情，权限变化记录提示仅保留日志 | 通过 |
| 导出凭证 | 明确凭证需单位盖章，到馆核验后才可出库 | 通过 |
| 待审批申请 | 待审批状态不能导出凭证，仅可查看申请 | 通过 |
| 拒绝原因 | 已拒绝申请可查看拒绝原因 | 通过 |
| 架位隐藏 | 页面未展示任何具体库房、架位或盒位信息 | 通过 |

## 4. 启发式评估验收

1. 系统状态可见性：借阅、查阅、下载和权限状态明确，符合。
2. 系统与现实世界匹配：使用借阅申请、凭证、出库、归还等术语，符合。
3. 用户控制与自由：用户可跳转检索或查看记录，符合。
4. 一致性与标准：复用后台壳层风格和公共组件，符合。
5. 错误预防：历史记录重新鉴权，凭证不视为出库，符合。
6. 识别而非记忆：近期查阅、借阅和下载集中展示，符合。
7. 灵活性与效率：高频入口和待办操作直达，符合。
8. 美观与简约设计：页面不混入管理员审批功能，符合。
9. 帮助用户识别、诊断并修复错误：权限变化、拒绝原因均有提示，符合。
10. 帮助与文档：利用边界说明清楚，符合。
