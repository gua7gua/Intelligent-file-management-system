## 4. 启发式评估验收

| 原则 | 结论 |
|------|------|
| 系统状态可见性 | 状态卡、列表标签、详情进度线均可见。 |
| 现实世界匹配 | 使用清单、回执、到馆移交、回退补交等业务语言。 |
| 用户控制与自由 | 草稿可返回编辑，提交后保留导出、查看进度和补交入口。 |
| 一致性与标准 | 状态名称与新版业务场景、数据库和 PUML 保持一致。 |
| 错误预防 | 明确提示移交单位不上传文件本体，提交后只读。 |
| 识别而非记忆 | 回退原因、下一步和流程节点直接展示。 |
| 灵活性与效率 | 支持标签筛选、关键字搜索、常用操作按钮和窄屏稳定审查。 |
| 美观与简约 | 页面聚焦经办人工作台，无多余后台字段。 |
| 错误识别与恢复 | 回退条目给出原因和“新建补交清单”路径。 |
| 帮助与文档 | 页面提示清楚说明文件上传边界和补交流程。 |

通过。页面覆盖移交单位经办人在工作台中查看清单状态、回退原因、入库和上架进度的核心需求，并符合移交单位门户权限边界。
