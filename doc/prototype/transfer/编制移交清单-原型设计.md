# 编制移交清单 - 原型设计

## 1. 页面概述

- 页面名称：编制移交清单
- 所属门户：移交单位门户
- 页面路径：`prototype/transfer/transfer-list.html`
- 使用角色：移交单位经办人
- 页面目标：让经办人填写清单级信息和条目级信息，支持拖拽电子文件在浏览器本地解析文件名、扩展名和大小，用于辅助填写清单，提交后生成待移交清单并导出打印。

## 2. 业务场景归属分析

- 所属业务场景：`new-doc/业务场景.md` 场景一“业务部门移交档案”的“编制清单”和“提交与导出”阶段。
- 涉及数据实体：`intake_batches`、`intake_items`、`business_attachments`。
- 清单级字段：清单标题、移交单位、移交部门、经办人、联系电话、档案所属年度、预计移交日期。
- 条目字段：档案标题、页数、保管期限、载体状态、电子文件格式、保密级别、是否公开、是否允许数字化、档案文件名、档案形成日期。
- 状态节点：
  - 清单批次：草稿 -> 待移交。
  - 清单条目：草稿 -> 待验收。
- 与上下游关系：
  - 上游：移交单位整理纸质原件和电子文件。
  - 下游：提交后前台管理员调取清单，核对纸质实物并上传 U 盘电子文件。
- 重要边界：移交单位侧拖拽文件只做浏览器本地解析，不写入 `staging_files`，不上传 MinIO；载体状态、密级、保管期限、是否公开、是否允许数字化必须由经办人选择或确认。

## 3. 用户与操作分析

| 角色 | 操作 | 路径类型 | 结果 |
|------|------|----------|------|
| 移交单位经办人 | 填写清单级字段 | 主路径 | 形成 `intake_batches` 草稿信息 |
| 移交单位经办人 | 拖拽或选择电子文件 | 主路径 | 本地解析文件名、扩展名、大小，生成或补充条目草稿 |
| 移交单位经办人 | 新增空白条目 | 主路径 | 手工填写纯纸质或未整理电子文件的档案 |
| 移交单位经办人 | 编辑条目字段 | 主路径 | 补充页数、载体、保管期限、密级、形成日期等 |
| 移交单位经办人 | 保存草稿 | 主路径 | 清单保持草稿，可回到工作台继续编辑 |
| 移交单位经办人 | 提交清单 | 主路径 | 批次变为待移交，条目变为待验收，可导出 PDF |
| 移交单位经办人 | 导出打印 | 主路径 | 下载清单 PDF，纸质签字盖章后随实物到馆 |
| 移交单位经办人 | 处理校验错误 | 异常路径 | 未填必填字段、载体状态缺失、纯纸质却填写电子文件等提示修正 |

## 4. 页面布局说明

- 公共壳层：使用 `app-shell`，左侧仅展示移交门户入口。
- 顶部栏：展示当前经办人、单位和“本页不上传文件本体”提示。
- 内容区：
  - 清单基础信息表单：清单标题、部门、联系电话、年度、预计移交日期等。
  - 本地解析上传区：拖拽或选择文件，显示“只解析不上传”的安全边界。
  - 本地文件列表：独立滚动展示已解析文件，避免大量文件挤压提交检查区。
  - 条目表格：可编辑各条目字段，载体状态使用下拉框由经办人确认；宽表格支持横向和纵向独立滚动，表头固定。
  - 校验摘要：展示待修正问题和受保护字段说明。
  - 提交确认区：保存草稿、提交清单、提交后导出打印。

## 5. 交互逻辑说明

1. 拖拽或选择文件后，页面调用浏览器 File API 读取 `name`、扩展名和 `size`，自动填充档案标题、档案文件名、电子文件格式。
2. 拖拽动作不改变载体状态，新增条目的载体状态默认留空，必须由经办人选择纯电子、纸质+电子或纯纸质。
3. 点击“新增空白条目”生成一条手工条目，适合纯纸质档案。
4. 点击“校验清单”检查清单级必填字段、条目载体状态、保管期限、密级、形成日期等。
5. 点击“提交清单”后在页面内完成校验和状态反馈，不使用遮罩弹窗；校验通过后模拟批次状态从草稿变为待移交，条目状态从草稿变为待验收。
6. 提交成功后显示“导出打印清单”按钮，跳转/下载意图保留为 PDF 清单。

## 6. 启发式自查记录

| 原则 | 自查结论 |
|------|----------|
| 系统状态可见性 | 草稿、校验结果、提交结果和导出状态均有反馈。 |
| 现实世界匹配 | 使用移交清单、预计到馆日期、签字盖章、页数、保管期限等业务语言。 |
| 用户控制与自由 | 支持保存草稿、删除未提交条目、返回工作台。 |
| 一致性与标准 | 字段与业务场景、数据库设计一致。 |
| 错误预防 | 明确提示“不上传文件本体”，并要求人工确认载体状态。 |
| 识别而非记忆 | 页面直接说明拖拽能填哪些字段、不能判断哪些字段。 |
| 灵活性与效率 | 支持批量文件解析、手工新增空白条目和长表格独立滚动审查。 |
| 美观与简约 | 表单分为清单级信息、文件解析、条目编辑三块。 |
| 错误识别与恢复 | 校验摘要列出具体问题和修正建议。 |
| 帮助与文档 | 页面内保留安全边界和线下交接提示。 |
