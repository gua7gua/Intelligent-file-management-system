# 编制移交清单 - 验收

## 1. 验收范围

- 页面：编制移交清单
- 路径：`prototype/transfer/transfer-list.html`
- 版本：静态高保真原型
- 验收依据：移交清单编制、提交、导出打印和“移交单位侧只解析文件名，不上传文件本体”的业务口径。

## 2. 功能验收项

| 编号 | 功能点 | 验收标准 | 状态 |
|------|--------|----------|------|
| F-01 | 移交门户壳层 | 左侧仅展示移交工作台、编制清单、草稿和回退补交入口 | 通过 |
| F-02 | 清单基础信息 | 展示清单标题、移交单位、部门、经办人、联系电话、年度、预计日期 | 通过 |
| F-03 | 本地文件解析 | 选择或拖拽文件后仅解析文件名、扩展名、大小 | 通过 |
| F-04 | 条目编辑 | 支持编辑标题、页数、保管期限、载体状态、密级、公开、数字化等字段 | 通过 |
| F-05 | 人工确认载体 | 拖拽生成的条目载体状态为空，必须由经办人选择 | 通过 |
| F-06 | 空白条目 | 支持新增空白条目用于纯纸质档案 | 通过 |
| F-07 | 校验清单 | 校验清单级必填项、条目必填项、涉密公开冲突、载体与文件名冲突 | 通过 |
| F-08 | 保存草稿 | 可模拟保存草稿，保持可编辑状态 | 通过 |
| F-09 | 提交清单 | 校验通过后状态变为待移交，条目变为只读 | 通过 |
| F-10 | 导出打印 | 提交成功后显示导出打印清单按钮 | 通过 |
| F-11 | 滚动审查 | 本地解析文件列表和条目编辑表格支持独立滚动 | 通过 |

## 3. 交互验收项

| 编号 | 交互点 | 验收标准 | 状态 |
|------|--------|----------|------|
| I-01 | 拖拽反馈 | 拖拽进入解析区时有高亮反馈 | 通过 |
| I-02 | 文件解析反馈 | 解析完成后显示“未上传”和本地文件信息 | 通过 |
| I-03 | 校验反馈 | 校验失败展示具体问题列表，校验成功展示可提交提示 | 通过 |
| I-04 | 提交保护 | 提交后输入项只读或禁用，符合提交后不可编辑规则 | 通过 |
| I-05 | Toast 提示 | 保存、解析、删除、提交、导出均有即时反馈 | 通过 |
| I-06 | 无遮罩提交 | 提交清单使用页面内校验与反馈，不弹出遮挡页面的确认窗口 | 通过 |

## 4. 启发式评估验收

| 原则 | 结论 |
|------|------|
| 系统状态可见性 | 当前草稿/待移交状态、校验结果、提交结果可见。 |
| 现实世界匹配 | 使用预计到馆、签字盖章、纸质原件、U 盘等现实交接语言。 |
| 用户控制与自由 | 未提交前可新增、删除、保存草稿；提交后进入只读。 |
| 一致性与标准 | 字段和状态与新版移交流程一致。 |
| 错误预防 | 页面反复提示不上传文件本体，载体状态必须人工确认。 |
| 识别而非记忆 | 解析区直接说明拖拽能填充和不能判断的字段。 |
| 灵活性与效率 | 支持批量解析文件、手工新增纯纸质条目和长表格独立滚动。 |
| 美观与简约 | 表单、解析区、条目表格、提交检查分区清晰。 |
| 错误识别与恢复 | 校验摘要给出具体条目和字段问题。 |
| 帮助与文档 | 页面保留线下交接提醒和字段保护说明。 |
