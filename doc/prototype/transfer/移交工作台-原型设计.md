# 移交工作台 - 原型设计

## 1. 页面概述

- 页面名称：移交工作台
- 所属门户：移交单位门户
- 页面路径：`prototype/transfer/overview.html`
- 使用角色：移交单位经办人
- 页面目标：让经办人查看本单位移交清单状态、回退原因、接收回执、入库进度和上架进度，并从工作台进入清单编制或导出打印。

## 2. 业务场景归属分析

- 所属业务场景：`new-doc/业务场景.md` 场景一“业务部门移交档案”。
- 涉及数据实体：`intake_batches`、`intake_items`、`business_attachments`。
- 关键字段：清单号、清单标题、移交单位、移交部门、经办人、联系电话、档案所属年度、预计移交日期、提交时间、接收时间、入库时间、上架时间、回执附件。
- 状态节点：
  - 清单批次：草稿、待移交、已接收、部分接收、待入库、已入库、已上架、已拒绝。
  - 清单条目：草稿、待验收、已接收、已回退、待入库、已入库。
  - 暂存电子文件：未上传、暂存、匹配成功、匹配异常、已归档。
- 上游关系：经办人在“编制移交清单”页面新建或编辑草稿，提交后进入工作台跟踪。
- 下游关系：前台管理员在“移交验收与电子文件上传”页面接收；后台管理员在“待入库与上架”页面生成正式档案、入库和上架。
- 权限边界：经办人仅能查看本单位、本账号相关清单和回执；不能查看管理员工作台、正式库房架位、其他单位清单或正式档案管理入口。

## 3. 用户与操作分析

| 角色 | 操作 | 路径类型 | 结果 |
|------|------|----------|------|
| 移交单位经办人 | 查看状态概览和清单列表 | 主路径 | 查询本单位清单统计 |
| 移交单位经办人 | 新建移交清单 | 主路径 | 跳转 `transfer-list.html` |
| 移交单位经办人 | 继续编辑草稿 | 主路径 | 跳转 `transfer-list.html?batch=草稿清单号` |
| 移交单位经办人 | 导出移交清单 PDF | 主路径 | 下载 `business_attachments.attachment_type = transfer_pdf` |
| 移交单位经办人 | 下载接收回执 | 主路径 | 下载 `receipt_pdf`，查看已接收条目和回退原因 |
| 移交单位经办人 | 查看回退原因 | 异常路径 | 展示条目级 `reject_reason`，提示下次新建清单补交 |
| 移交单位经办人 | 查看入库/上架进度 | 主路径 | 展示批次状态和条目状态汇总，不暴露库房架位 |

## 4. 页面布局说明

- 公共壳层：使用 `app-shell`，左侧仅展示移交门户入口。
- 顶部栏：显示当前角色、单位范围、联系电话快捷信息。
- 内容区：
  - 状态统计卡片：草稿、待移交、部分接收、已上架等数量。
  - 流程进度条：编制清单、前台验收、后台入库、确认上架。
  - 筛选工具栏：按状态、年度、关键字筛选。
  - 清单列表：展示清单号、标题、年度、预计移交日期、条目数、状态和操作。
  - 右侧详情区：展示选中清单的批次信息、条目状态、回退原因、回执和下一步提示。
  - 响应式审查：工作区子卡片可按容器宽度收缩；长表格只在表格容器内横向滚动，不撑破页面。

## 5. 交互逻辑说明

1. 点击“新建清单”跳转到 `transfer-list.html`。
2. 点击状态筛选标签，列表按批次状态过滤，同时保留当前详情。
3. 点击清单行，右侧详情区切换为该清单的状态流转、条目明细和可执行操作。
4. 草稿清单显示“继续编辑”；提交后的清单只读，只允许导出清单或查看进度。
5. “部分接收”清单突出显示已回退条目和回退原因，并提示“回退条目不占用正式档号，下次新建清单补交”。
6. “已入库/已上架”仅展示业务进度和可公开给移交单位的正式档号摘要，不展示具体库房架位。

## 6. 启发式自查记录

| 原则 | 自查结论 |
|------|----------|
| 系统状态可见性 | 使用状态卡、标签和流程条展示批次、条目、文件状态。 |
| 现实世界匹配 | 使用清单、回执、入库、上架、回退原因等档案业务术语。 |
| 用户控制与自由 | 草稿可继续编辑，提交后保留导出和返回工作台入口。 |
| 一致性与标准 | 状态名称与业务场景、数据库枚举和状态机一致。 |
| 错误预防 | 提交后只读，避免经办人误改已进入验收流程的清单。 |
| 识别而非记忆 | 详情区直接列出下一步和回退原因，不要求用户记住流程。 |
| 灵活性与效率 | 支持状态筛选、关键字筛选、一键进入新建清单和窄屏稳定审查。 |
| 美观与简约 | 页面聚焦工作台、列表、详情，不展示后台管理字段。 |
| 错误识别与恢复 | 回退条目显示原因和补交流程，避免只给出失败状态。 |
| 帮助与文档 | 页面内以提示条说明“移交单位不上传文件本体”和“回退条目新建清单补交”。 |
